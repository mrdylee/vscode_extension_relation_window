# 0.1.1 리뷰 수정 검증 — 2026-10-17

## 수정 범위

1. 함수 내부 초기화 식의 직접 호출은 실행하는 함수에 연결한다. 함수 주소를 저장하는 변수의 참조 노드는 유지한다.
2. 함수 원형·중첩 콜백의 매개변수는 해당 매개변수 목록에 범위를 제한한다. 실제 정의의 매개변수는 함수 본문에서 이름을 가린다.
3. `for` 초기화 변수의 범위는 해당 반복문까지이며, 본문의 더 좁은 블록 범위는 유지한다.
4. 미확정 조건의 `static` 정의만 있으면 외부 정의 또는 선언도 후보로 남긴다. 무조건 정의와 확정된 `#if 1`의 기존 우선순위는 유지한다.
