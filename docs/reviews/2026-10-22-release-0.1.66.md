## Windows CI finding and correction

- Run 39716187510 passed every macOS and Ubuntu check. Windows unit tests reached
  the resume assertion after a fixed 1.1s sleep while only five of the expected
  eight requests had started. Seven requests follow a one-second scheduler delay;
  file I/O and provider completion are not guaranteed to fit in the remaining 100ms.
- Reproduced locally by adding 25ms provider latency to the seven-site resume test.
  Its old fixed sleep fails, while completion-based waiting passes with that delay.
- Relevant new lifecycle tests now observe terminal diagnostics with a bounded
  timeout. Stop/cache restoration and background five-site checks also await their
  completed states. Deliberate negative tests retain waits where needed to prove
  that a scheduled request does not start.
- The failed CI gate prevented 0.1.65 publication. Existing version tags were not
  moved; the corrected release uses a new 0.1.66 version and tag.
