# Release review: 0.1.65

## Scope

Reviewed automatic Copilot execution/cancellation, AI function navigation, their
tests and documentation, version metadata, and restored cross-platform release CI.

## Findings and resolutions

- A one-click full run must not repeatedly reset the five-request cache budget or
  progress. Continue sequential batches inside one controller run with cumulative
  counters. Forced reanalysis invalidates old records once and visits each site once.
- User Stop must cancel an uncooperative provider, preserve completed/cache-valid
  results, and prevent a pending local-index wait or save event from restarting the
  job. Abort with an explicit user-stop reason, retain only current-snapshot results,
  cancel deferred work and guard commands against a late start.
- Active jobs wait during dirty-source/local-analysis changes and resume after a
  stable saved index. Errors stop new automatic requests instead of retrying. Keep
  cache-only startup/navigation and the five-request background save limit.
- AI candidate nodes previously selected the original callback callsite and were
  excluded from click/tooltip expansion. Share navigation/expansion rules between
  the host and webview: select the candidate definition, open it with double-click
  or Enter, and explore its real callees. Keep callsite/evidence links and uncertainty.
- The universal package contains JavaScript/WASM and no native runtime dependencies.
  Restore Windows/macOS/WSL filename copies plus the former Windows/macOS/Ubuntu
  test matrix. Keep the common/legacy names used by automatic updaters.

## Validation evidence before publication

- Local build and typecheck passed; all 424 unit tests passed.
- Regression coverage includes one-command analysis of 38 sites, monotonic progress,
  forced cache refresh, stop after seven completed results, continuation of only the
  31 remaining sites, late command cancellation, saved-source resumption, and stopping
  on request errors. Existing model/consent/timeouts and cache-only behavior pass.
- Host tests reproduce the cross-file AI navigation defect before the fix and pass
  afterward in Callees and Both modes. Candidate function preview/open/expansion and
  separate callsite navigation preserve incomplete AI results.
- Browser UI checks passed using Chromium, including Analyze/Stop and paused-job
  controls, candidate definition click/Enter/double-click, expansion actions and
  original invocation links. Existing navigation/layout checks also passed.
- Cross-platform CI and public package verification are recorded after publication.
  Live user-side WSL remote installation is not verified here.

No unresolved blocking findings were identified in the reviewed change.
