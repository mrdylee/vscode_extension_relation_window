# Saved symbol slots review and release: 0.1.83

## Scope and corrected finding

Reviewed the complete saved-slot and Backspace implementation against the agreed
requirements: exact right-click targets, independent locks, persistence ordering,
current-source and including-unit identity, branch restoration, focus recovery,
editable-field behavior and expansion-history invalidation.

An expansion arriving after an index update but before the view refreshed could
save obsolete history. `changeExpansion` captured the old view, refreshed (which
cleared history for the new files), then pushed that obsolete capture into the
new history. The new regression first failed with `canGoBack === true` after a
source revision, where history should have been empty.

Keep a snapshot only if the original history array survives refresh. This guards
the existing invalidation boundary without changing ordinary expansion, slot
contents or analysis. The regression now passes and Back leaves the new view
unchanged after this race. No analysis limits or cache version changed.
