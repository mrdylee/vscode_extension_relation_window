# Release review: 0.1.67

## Scope

Includes compatible-index reuse, AI candidate replacement, editable Copilot
Include/Exclude scope and additional Combined panel alignments. The follow-up
review fixes cancellation during startup/model selection, simultaneous JSON scope
edits and AI confirmation of partial local candidates without duplicate counts.

Detailed evidence:

- [Index compatibility and AI replacement](2026-10-22-index-compatibility-ai-replacement.md)

remain outside this release's fixes. Analysis-cache compatibility starts at
version 1, independently of package version. Existing unversioned caches require
one manual Rebuild; subsequent compatible releases reuse the saved index.
