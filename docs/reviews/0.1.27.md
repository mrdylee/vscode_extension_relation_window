# review-work — v0.1.27

## Scope and method

Local code review of the release candidate against v0.1.26, including the
resolver changes, regression tests, VS Code integration, version metadata,
README release gate and release notes. No external review service or review
subagent was used. This is a review record, not a guarantee of complete C
semantic analysis.

## Findings and resolution

1. **P2 — Missing implicit local tag completion.** A declaration such as
   `struct Motor *m` can introduce a local tag that is completed later in the
   same block. Resolve that completion only when no unconditional outer tag is
   already visible. Pass the declaration scope through typedef normalization so
   an enclosing block or a later global definition cannot substitute for it.
   Regressions cover the original reproducer, earlier file/header definitions,
   later global definitions and rejection of an enclosing-block completion.
2. **P2 — Conditional local receiver drops outer candidates.** Walk lexical
   scopes until an unconditional declaration hides the outer scopes; retain
   possible outer/global declarations when nearer declarations are conditional.
   Regressions cover member candidates, multiple nested scopes, unconditional
   shadows, callback/function ambiguity and block extern linkage.
3. **Review follow-up — Scope boundary in the first fix.** The initial fix could
   pick a later definition in an enclosing block. Added a failing regression,
   restricted completion to the declaration's exact scope, and re-ran tests.

The original reproducers failed before the fixes. After the scope follow-up,
all 75 unit tests pass. The changed resolver paths were inspected for stale
indexes, conditional candidate loss, incorrect ordinary-name shadowing and
unbounded recursion. No further actionable finding remained in this review.
Existing documented limitations (macro expansion, runtime pointer targets,
casts and other unsupported receivers) remain unchanged.
