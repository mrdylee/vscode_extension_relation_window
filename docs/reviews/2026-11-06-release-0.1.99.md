# Dynsight 0.1.99 release review

Reviewed the host's visibility and focus checks, the webview's input handlers,
and the one-minute timer. An activity change in the main editor sends the
same availability state while the Relation view is visible and VS Code
has focus. The webview keeps its timer when it receives that state again.

The one-minute appearance check failed with the 0.1.98 build and passed with
the new behavior. Browser tests cover the 60-second boundary, duplicate host
signals, pointer movement, restarting after panel input, and cancellation
when the view becomes unavailable.

Typecheck, 912 unit tests, and both browser UI suites passed. The VSIX
contained 19 verified files and passed the macOS Extension Host integration
suite from an isolated extracted copy.
