# Installed AI extensions and no-ID release: 0.1.87

## Delivered behavior

Smart Analysis selects one installed Copilot, Claude Code or Codex extension. Auto chooses the single installed provider or asks once when several are installed, saving the choice. Only that provider receives requests; changing it cancels the previous request, and failures do not fall back. Claude/Codex use their bundled engines with default models, without separate CLI installation, executable paths or model ID inputs/settings. Obsolete manually entered IDs are ignored. Copilot retains its available-model list. Existing source scopes, manual confirmations, validation, caches, stop/resume and legacy commands remain supported. Local analysis cache compatibility remains 16.
