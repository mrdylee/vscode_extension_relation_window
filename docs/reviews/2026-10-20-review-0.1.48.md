## Reproduction and change

The previous lock action only toggled tracking, retaining the old root even after
the user clicked a different Relation node. Native VS Code regression reproduced
this: selecting check_fault under control_task and pinning retained control_task.

Track the selected graph node separately from the Context preview location.
Call sites cannot identify the desired pin by their enclosing function.
Resolve the selected node's symbol through the current index before pinning.
Reset stale node selection when it disappears or the root changes.

A node context-menu action replaces the pin without toggling following on.
Unknown/stale keys are ignored. Unresolved nodes and the graph background do not
offer this action. The existing root marker and return-to-pin action use the new
root; index processing and graph traversal algorithms are unchanged.
