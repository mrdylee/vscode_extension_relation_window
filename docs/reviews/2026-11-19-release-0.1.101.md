# Dynsight 0.1.101 release review

Reviewed the compilation database importer and C analysis changes in `73e8642` against `v0.1.100`. Four findings were reproduced and fixed in `ebc61be`.

- A literal `#elif 1` could hide the shared body and trailing C `else`. The regression test checks both callback assignments and the calls in reachable headers.
- A callback declared in the shared block could bind to an outer variable of the same name. The test checks the call inside the block and the following call outside it.
- A Windows command could lose quotes around a string macro. The test compares the parsed command with the equivalent argument array.
- Filesystem paths containing URI delimiters could be skipped or fail normalization. The test checks the source, output, include directory, and response file.

All four regression tests failed before the fixes. Type checking, 928 unit tests, and 150 Worker tests passed on Node 22. The analysis cache version is 21 so previously saved callback results will be rebuilt.

The local VSIX passed ZIP integrity checks. Both manifests identify version 0.1.101, and the packaged files under `dist/` match the local build.
