# Callback table recovery review — 0.1.50

Local review against `2b023060970a0f46adca48035a125cfed1e10f6a`.

## Findings and fixes

- Explicit designators were discarded when a structure layout was absent.
  Preserve those object-specific slots without guessing positional fields.
  Same-name members in unrelated objects remain separate.
- Forward aggregate declarations discarded pointer and function-return layers.
  Keep those layers without inventing member declarations.
- Missing callback paths returned generic or empty reasons. Identify unavailable
  getter bodies, unsupplied parameters, object/member values and layouts; expose
  reasons in the existing callback selection UI without an extra analysis pass.
- Macro/callback limits could still report Index ready. Reflect these notices in
  Partial index while retaining existing precedence for memory and file failures.

## Boundaries

No heap-budget increase, new cache, source-wide query on selection, or name-only
callback matching. Reasons describe available analysis evidence, not a complete
runtime trace or a proven first cause. Positional layout inference and arbitrary
memory mutations remain unsupported. The private WSL firmware is unavailable;
its exact failing stage remains unconfirmed.
