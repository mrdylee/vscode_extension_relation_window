# Release review: 0.1.71

Includes the complete manual-control change and evidence in
[the unpublished 0.1.70 candidate review](2026-10-22-release-0.1.70.md), plus two
corrections found by its native CI:

- Set the resolving status before request dispatch, so a synchronous Worker error
  can replace it with the fatal state and keep that state through completion.
- Cache the Relation graph by settings/root and FileAnalysis identities. Status
  and diagnostic refreshes preserve the graph; source and graph-setting changes
  invalidate it. Explicit refresh consumes any pending debounce timer.

Local regressions verify both paths: panel tests pass all four cases including
graph reuse/invalidation; all 43 workspace tests pass including synchronous fatal
dispatch and Stop/Retry in both propagation and registration postprocessing.
TypeScript checking passed. Existing tags remain unchanged; v0.1.70 had no assets
published. Analysis compatibility remains 3 with automatic derived-cache migration.

Original firmware performance and live user-side WSL installation are unavailable
for validation. Native CI and published downloads require final verification.
