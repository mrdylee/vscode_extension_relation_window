# Release review: 0.1.80

## Regression and correction

Reported on WSL0.1.79 with a selected Build: previously AI-resolved callback
arrows lost their targets. Navigation falls back through `indexFor(uri)` to the
basic source index when no contextual facts exist. AI snapshots, projection and
manual actions used only the Build index. An empty/partial compile projection
therefore omitted basic-navigation call sites and could not publish their hints.

Expose both callback indexes. Snapshot both and isolate basic/contextual evidence
builders, retaining raw support definitions while suppressing duplicate raw sites
covered by contexts. Project validated hints and manual actions into the matching
index. Preserve translation-unit/static identity, validation, settings/model keys,
cache compatibility14, analysis/request/memory limits and source scopes.
