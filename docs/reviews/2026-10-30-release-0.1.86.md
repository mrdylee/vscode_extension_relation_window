# Bilingual offline manuals release: 0.1.86

## Scope and review

Publish the user's requested Korean/English manuals and prominent in-extension
help access. The reviewed implementation is documented in
`2026-10-29-bilingual-user-manual.md`. Changes are limited to bundled manuals,
language-specific Help commands, toolbar emphasis, Settings links, corresponding
native/browser checks and release metadata. Analysis cache compatibility remains
16; analysis behavior and budgets are unchanged.

Review checked the actual manifest's 13 visible settings, current folder-picker
and navigation behavior, packaged offline paths and state preservation. Narrow
settings tables and Korean Markdown emphasis were corrected during local review.
No remaining blocking issue was found in the reviewed scope.
