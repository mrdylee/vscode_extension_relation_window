# Release review: 0.1.70

## Scope

Remove the project-wide callback deadline and add per-function timing plus manual
Stop/Retry. Preserve memory, work, mutation/region and convergence bounds. A shared
atomic signal reaches the busy Worker during propagation, macros and registration
postprocessing. Preserve discovered targets/registration facts and partial status.

The subsequent review found two gaps: registration postprocessing ignored Stop,
and a stopped expression still reported a time-budget reason. Both are corrected.
Registration traversal checks cancellation, retains its collected prefix, reports
the registration stage and avoids caching incomplete output. Retry uses parsed IR.

Analysis cache compatibility stays at 3. A manual-stop policy marker and retryable
generation flag invalidate old/transient derived data without discarding raw IR.
Valid 0.1.69 caches migrate automatically; no mandatory manual rebuild is added.

## Evidence before publication

- All 525 unit tests passed; both original review probes now pass.
- All 51 Worker/cache/workspace tests passed under Node 22, including real Stop
  during final registration collection, retained targets, Retry completion and no
  additional source parses. Unchanged source notifications do not cancel a pass.
- All four memory/cache collection tests passed under Node 22.
- TypeScript checking and production build passed.
- Browser verification passed for a live per-function timer, a five-second slow
  indication without an automatic stop, timer reset at the next function, stable
  Stop button identity across updates, Stop/Retry messages and a single-line
  footer at 1280/900/520px.
- Original review probes: registration-entry Stop now reads the signal and
  processes zero of the 10000 pending registrations, instead of processing all
  10000. Manual cancellation no longer adds a time-budget reason.
