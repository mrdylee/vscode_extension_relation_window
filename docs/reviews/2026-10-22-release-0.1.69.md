# Release review: 0.1.69

## Scope

Includes the fixes and permanent regressions documented in
[the offset-analysis review](2026-10-22-offset-analysis-review.md): separate
address/data dependencies, compose pointer offsets consistently and recover
valid GNU attribute declarations without hiding unrelated parse errors.

Analysis compatibility advances from 2 to 3. Existing indexes require one
Rebuild after upgrading. The callback mutation/region and time limits remain
unchanged. No actual firmware sources or user settings were modified.

## Evidence before publication

- All 514 unit tests passed, including 28 additional permanent regressions.
- All 47 Worker/cache/workspace tests passed under Node 22. The new fixture
  combines 400 dynamic-offset writes, GNU attribute recovery and the corrected
  callback target, with Index ready and no false limits.
- All four memory/cache collection tests and index performance validation passed.
- TypeScript checking, production build and all seven original review probes
  passed.
- The native Extension Host fixture now exercises dynamic-offset byte packing
  and a trailing GNU section attribute. Release CI must verify it on Windows,
  macOS and Ubuntu before publication.

The original 196-file firmware project is unavailable here. Its actual runtime
and live WSL remote installation are unverified.
