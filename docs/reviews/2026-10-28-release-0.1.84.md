# Compact slot padlock release: 0.1.84

## Scope

Overlay the existing padlock button on the upper-right corner of each slot
number. Empty, unlocked and locked slots retain a fixed 24 px width. The lock
button remains independently clickable within those bounds; normal number
clicks, tooltips, context menus and Backspace navigation retain their behavior.
Update the corresponding guide wording. No host/navigation/analysis code changed.
