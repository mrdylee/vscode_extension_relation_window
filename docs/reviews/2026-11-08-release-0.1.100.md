# Dynsight 0.1.100 release review

Reviewed the changes from main commit
`eb23330a357b667ac3a013d74f3db3e6b6198de5` through the Salgu timer,
pointer handling, scene keyframes, sprite layout, and release metadata.

The scheduler draws a fresh 10–20-second interval for every appearance.
The longest scene lasts nine seconds. Direct function-name clicks stop the
current scene and restart the wait. Pointer movement beyond the existing
six-pixel drag threshold cancels click tracking. Wheel input, variable
selection, dragging, and automatic graph refreshes preserve the timer.
Visibility and focus changes control availability, and reduced motion
suppresses animation.

All 20 scenes use the shared 384-by-672 sprite sheet. Daily scenes animate
their poses, and yawning, dozing, and sleeping also move during held poses.
The sleeping scene anchors breathing to the sill. Scene completion and
availability changes cancel active animations. The review found no
unresolved issues in this scope.

## Validation

- Typecheck and 912 unit tests passed.
- Both browser UI suites passed. Timer coverage includes the ten-second
  lower bound, twenty-second upper bound, a fresh fifteen-second interval
  after a function click, repeated playback, duplicate availability signals,
  and cancellation when the view becomes unavailable.
- Browser tests exercise all 20 scenes, click-versus-drag handling, blinking,
  motion during held poses, grounded breathing, and reduced motion.
- The local VSIX passed ZIP integrity checks and contained 19 verified files.
  Its manifest is version 0.1.100. Packaged build outputs matched the tested
  build, including the 106,790-byte sprite image and ten-to-twenty-second timer.
- The extracted VSIX passed the macOS Extension Host integration suite in an
  isolated workspace and profile, and the host exited with code zero.
