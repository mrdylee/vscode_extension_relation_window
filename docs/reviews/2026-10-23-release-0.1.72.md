# Release review: 0.1.72

Review scope: the approved scoped-analysis/settings design and implementation
plan, all runtime changes from `8160f3f`, and the embedded C parser changes
already committed after the published `v0.1.71` tag. Local `review-work` inspected
the diff, traced runtime entry points and checked requirements against tests.
No separate review agent or unavailable review command is claimed.

## Review and correction loop

1. **User confirmations could lose Recheck with AI after local resolution.**
   Context collection intentionally skipped complete static calls, including a
   still-valid user-confirmed invocation after local analysis resolved it.
   Valid explicit manual actions now include only their selected site in context
   collection. Startup restoration still skips complete calls and sends no AI
   request. A regression failed with “This callback changed” before the fix and
   passed after it; the selected user target remains unchanged.
2. **Changing a manual target after restart could discard registration
   dependencies.** With Copilot OFF, the old hint map was empty. Reconstructing a
   choice retained source/target files but lost the registration evidence file,
   allowing later registration edits to escape review. Target changes now carry
   previous dependency URIs and the selected new AI suggestion's evidence. The
   regression failed on the missing dependency before the fix, then verified
   `Needs review` and overlay removal after a registration change.
3. Repeated the local review after both corrections. Checked manual-only AI
   entry points, no stale result application, overlay separation, serialized
   workspace storage, explicit legacy/unified settings, per-root scope, basic
   IR/host transfer, cancellation and bounded uncertainty. No further blocking
   finding remained in this reviewed scope.

## Local validation

- Typecheck/build and all **535 unit tests** passed.
- **54 Worker/cache/workspace** and **5 memory** tests passed.
- Relationship index performance and both Playwright UI suites passed. The
  expanded scoped suite also covers AI agreement, insufficient context, Escape,
  duplicate-name path selection and a late response after manual replacement.
- Native VS Code extension integration passed. FreeRTOS indexed all **656**
  files in basic and full-detail modes; full detail correctly remains partial at
  its work bound. The large-workspace test indexed **2,501** selected files from
  **12,551**, checking **50,000** direct calls.
- The fixed performance fixtures preserve six callback edges across five target
  names: independent scalar data, distinct objects sharing a field name, getter
  → third argument → global callback, and a callback array selector. Basic mode
  creates no inferred edges.
- The real FreeRTOS Stop probe observed cancellation about **421 ms** after the
  request while retaining source facts. This is one measured sample, not a
  latency guarantee for the user's firmware.
- The local VSIX contains 16 entries. Its six runtime JS/CSS/WASM files match
  the reviewed build byte for byte; source/tests/node_modules are excluded.

Whole-project detailed analysis can still hit work or memory protections. Real
Copilot model accuracy and the actual Windows SafeRTOS/Wind River workspace are
not claimed as verified. Generic native CI is checked separately at publication.
