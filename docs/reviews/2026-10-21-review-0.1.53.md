# Callback effects review — 0.1.53

Baseline: `checkpoint/pre-sparse-callback-effects-20261020` (`1f2c1c6`).
The recovery tag was pushed before edits. Scope is sparse effect export and
bounded uncertainty in the existing no-build analyzer; no increased protection
limits, new setting, selected-function-only index, or AI inference.

## Reproduction and implementation

Two baseline failures used 270 and 2700 unread scalar fields plus one callback:
both reached the 256-slot mutation limit and marked the known target incomplete.
The first stage omits only proven unread scalar declarations from exported
effects; evaluation and heap storage remain. Reads used only for guards/payloads,
array paths and unresolved types can still be retained. This is deliberately
more conservative than a full callback-specific backwards slice.

Four additional baseline failures covered a wide opaque object, helper parameter
invalidation, nested pointees, and unrelated-limit contamination. Opaque changes
now use ordered regions with explicit strong/conditional semantics. Regions are
substituted through formal parameters and applied on reads, without one effect
per descendant. Exact later writes restore only their own storage; copied values
retain their independent history.

## Review findings fixed

- Missing cross-file scalar effects: compatible structure declarations can have
  different field IDs. Conservatively retain read member names for effect
  eligibility without merging the values of unrelated objects.
- Omitted global effects: functions with no pointer arguments can still modify
  global callbacks. Carry omitted slots as uncertain regions so a caller's
  earlier strong value cannot hide the dropped change.
- Conditional helpers: preserve the untouched branch as an incomplete candidate
  rather than invalidating it unconditionally.
- Cross-call contamination: concrete parameter supplies assist local analysis
  but are not exported as other callers' objects in symbolic region summaries.
- Array ordering: exclude nonexistent broad slots and mask older wildcard writes
  after an exact assignment; retain wildcard writes that occur later.
- Join bounds: enforce the region cap while merging branches, not only during
  individual mutations and summary export.
- Performance: the initial region implementation scanned unrelated objects.
  Index region membership by storage root; retain prefix/wildcard matching.

Independent review agents added concrete failing regressions before fixes.
Their focused second reviews found no further reproduced important defects.
Existing global memory/time/work/loop/array/nonconvergence limits remain
conservative; mutation-limit incompleteness is localized through affected storage.

## Measurements

Seven alternating inference runs per version on the same parsed sources, after
warm-up. Baseline `1f2c1c6`; current working tree after the review fixes.
Times exclude parsing, macro expansion, Worker transfer and UI updates.

| Synthetic scenario | Before median | After median |
| --- | ---: | ---: |
| 270 unread scalar writes | 2.070 ms | 2.213 ms |
| 2700 unread scalar writes | 23.135 ms | 22.994 ms |
| One opaque call, 2700 slots | 35.683 ms | 32.452 ms |
| Lane/group callback copy | 1.886 ms | 2.182 ms |
| 128 independent opaque objects | 3.812 ms | 4.124 ms |
| 320 independent opaque objects | 10.349 ms | 10.720 ms |
| 320 separate functions/objects | 10.905 ms | 12.724 ms |

Scalar false warnings disappear; the wide opaque call remains unresolved without
a mutation warning. The lane/group case retains rack/RBMS candidates with the
same conservative incomplete status. At 320 objects in one function, the
256-region guard retains unknown leaves and marks remaining candidates incomplete.
This is not evidence of a universal indexing speedup or a private WSL fix.

The initial implementation's 320-object median was 177.946 ms; storage-root
indexing reduced it to 10.720 ms before release. Sampled heap growth for 2700
scalar writes was 15.96 → 15.85 MiB; wide opaque 15.85 → 15.81 MiB;
128 objects 9.16 → 10.20 MiB. Samples are pressure-check/return observations,
not exact allocations or continuously measured peaks.
