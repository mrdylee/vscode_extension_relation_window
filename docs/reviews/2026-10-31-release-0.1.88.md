# One AI setting and guided model selection: 0.1.88 release

## Delivered behavior

**Smart Analysis: AI** is the sole visible AI control. Checking it immediately opens an installed-extension picker, followed by that extension's model picker. Models are selected by display name; Claude/Codex also offer an explicit default-model choice. No typed model IDs are required. The completed provider/model pair is saved together. Cancelling preserves the previous pair and turns a newly enabled checkbox off in its original User or Workspace scope. The same setting links to the complete flow for changes. Only the selected provider/model handles analysis requests; switching cancels the prior request, and failures do not switch providers. Existing source scopes, caches, evidence checks and manual confirmations remain supported. Analysis cache compatibility remains 16.
