# Dynsight 0.1.98 release review

Reviewed the Relation webview's visibility and activity handling, scene
clipping, reduced motion, and packaging of the shared Salgu sprite. The host
sends an idle signal only for a visible Relation view in a focused idle window.
The sprite is packaged with the webview and loaded through its local resource
policy.

The previous first-idle path could show Salgu immediately. A browser regression
reproduced the early appearance. The idle transition now starts the same
three-minute wait as panel input. Virtual-clock checks cover the exact delay,
the restart after panel input, and cancellation when workbench activity
resumes.

Typecheck, 912 unit tests, and both browser UI suites passed. The browser tests
also cover the ten scenes, edge clipping, and reduced motion. The VSIX
contained 19 files, including the 43,936-byte sprite, and passed the macOS
Extension Host integration suite from an isolated extracted copy.
