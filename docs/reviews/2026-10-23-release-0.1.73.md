# Release review: 0.1.73

## Final plan audit and correction loop

After publishing 0.1.72, a requirement-by-requirement audit found that Task 4's
basic-first contract was incomplete: symbols/direct calls appeared early, but
registrations and literal function arguments were still projected only after
detailed work. A real Worker/Host regression observed the first macro phase and
failed because those basic facts were absent. 0.1.72 tags and assets are preserved;
this follow-up completes the missing contract.

- Add an inexpensive registration/literal-argument pass without macro expansion
  or pointer propagation. Publish additional facts before detailed work. Host
  application reuses its source/symbol/raw-reference objects; the intermediate
  message carries no source text, symbols or propagation IR.
- Basic/AI readiness waits for that publication or a validated derived snapshot.
  Stop during initial registration collection retains its prefix; later Stop
  and memory limits retain all already-published basic facts. Retry reuses parsed
  sources. Base registration diagnostics keep their cancellation stage and share
  the existing 64-entry project cap with detailed notices.
- Reuse basic snapshots for unchanged raw identities and invalidate them on
  remove/reset/replacement. Send base deltas only for raw host inputs so warm
  no-change results cannot replace a complete detailed view with a basic one.
- Guard basic messages by request ID, source revision/raw versions and policy
  key. A second review regression also proved that a late basic message could
  overwrite an already-fatal Worker status; it failed before adding the fatal
  guard and passed afterward. Paused status is preserved too.
- Preserve pre-unified/unversioned legacy roots while keeping unconfigured
  unified-policy workspaces basic on upgrade. Cache compatibility is 6; old
  incompatible snapshots require Rebuild. User overrides are separate.
- Explicit legacy callback setting changes now refresh the cached root policy.
  A regression reproduced ignored enable/removal changes on a previously basic
  workspace; both transitions pass after clearing that policy cache.
- Copy now accepts bounded Unicode function-name snapshots. The prior ASCII-only
  check silently rejected them; over-limit names also receive failure replies so
  the existing selectable-name fallback is shown. A Host regression failed
  before the fix and passed afterward; native clipboard checks include Unicode.

The postprocessing Stop regression now distinguishes cancellation during basic
collection from cancellation after complete basic publication. The latter must
keep the full registration set instead of the old truncated-set expectation.

## Verification

- Typecheck, **536 unit**, **60 Worker/cache/workspace**, **5 memory**, index
  performance and both Playwright suites pass. Worker tests inspect the actual
  publication-before-macros ordering, argument/registration visibility, retained
  callback navigation after Stop, compact message payload, stale generations,
  fatal-status preservation, warm identities and cache migration.
- Native extension, FreeRTOS basic/full and the 50,000-call large-workspace
  tests pass. Full FreeRTOS detail remains partial at its analysis bounds.
- The performance harness now records actual basic-fact publication time.
  On the same 656-file FreeRTOS input, basic facts were ready at about 6.83s
  in basic scope, 6.59s in partial scope and 6.63s in full scope. Full detail then
  ran to its work bound; these are sample timings, not coverage/latency guarantees.
- The six-edge fixed callback fixture still passes. The Stop sample observed
  cancellation about 486ms after the request while preserving published facts.
  Full detail's memory protection remains active; no claim of eliminating all
  large-project memory limits is made.
- Repeated the callbacks-OFF measurement with the final Worker too: full macro
  scope cold/warm/disk-retry/edit samples were 9.553/7.043/2.988/8.663s; partial
  macro scope was 1.701/0.001/1.223/1.910s. Whole scope remains limited, so these
  samples do not imply complete expansion. JSONs are under
  `test-results/analysis-0.1.73-{macros,partial-macros}.json`.

Actual SafeRTOS/Wind River firmware behavior and live Copilot accuracy remain
unverified. Generic native cross-platform CI and public downloads are verified
separately at publication.
