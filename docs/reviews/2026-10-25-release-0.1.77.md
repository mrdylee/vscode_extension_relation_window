  compiler defaults, final source/link membership and the private firmware are
  unverified. Existing analysis limits and partial-result reasons remain active.

  program callback completeness. Synthetic variant reductions are not a measured
  speedup or resolution of the user's private firmware callback-limit issue.

  Native macOS development-host package validation is not user installation.
