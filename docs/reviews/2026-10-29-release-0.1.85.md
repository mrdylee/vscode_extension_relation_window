# Complete saved trees and action undo release: 0.1.85

## Scope

Save the complete Relation root and caller/callee tree, expansion/collapse states
and view options while retaining the exact right-clicked target as the selected
symbol. Preserve follow/pin state across recall and source/build file changes.
Backspace undoes expansion/collapse without restoring a previous selection or
Context. Preserve the old view after source-open failure and prevent an earlier
open timeout from releasing a later open's tracking guard. Existing slot locks,
legacy records, analysis cache compatibility 16 and analysis limits are retained.
Old descendant-only slots must be saved again to capture previously unrecorded
parent/sibling branches.
