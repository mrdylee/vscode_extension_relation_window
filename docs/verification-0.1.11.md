# 0.1.11 선택 추적 검증

## 재현

수정 전 실제 VS Code Extension Host에서 다음 네 회귀 조건이 실패했습니다.

1. `writer`를 단어 전체 선택하면 기존 `state` 관계에 머무름.
2. 같은 함수 내 커서 이동에서 관계 그래프를 다시 생성함.
3. 선택한 파일의 색인이 아직 없을 때 클릭하면 색인 도착 후에도 이전 관계에 머무름.
4. 고정 중 다른 코드 창으로 이동한 뒤 해제하면 이전 창의 관계에 머무름.

## 수정 후

- 네 조건 및 기존 통합 검증 통과. 크기 제한과 분석기의 심볼 해석은 변경하지 않음.
- 단위 테스트 33개 통과.
- macOS FreeRTOS 전체 655개 파일: 10,754ms, 분석 실패 0, 색인 중 에디터 문서 열기 0.
- 3단계 자동 추적: `vTaskSuspendAll` 108ms, `xTaskResumeAll` 104ms, `uxCurrentNumberOfTasks` 105ms, `xSchedulerRunning` 108ms.
- 위 시간은 로컬 선택 이벤트부터 확장 상태 반영까지이며 WSL 원격 전송 및 화면 페인트 시간은 포함하지 않음.
- 사용자 보고의 Polyspace 파일 크기 초과는 별도 사항. 오류 문구상 파일당 2,000,000자 제한으로 제외된 경우이며, 사용자 WSL 파일 원문은 미확인.

릴리스용 Windows/macOS/Ubuntu 검증 결과는 GitHub Actions에서 확인합니다.
