# Dynsight 0.1.87 — Smart Analysis with one installed AI extension

Smart Analysis에서 VS Code에 설치된 **Copilot / Claude Code / Codex** 중 하나를 사용합니다.

- **Smart Analysis: AI**를 켜고 분석할 Include 범위를 지정하세요. 확장이 하나면 자동 선택하며, 여러 개면 한 번 선택해 저장합니다. **Dynsight: Select AI Extension**으로 변경할 수 있습니다.
- **선택한 하나만** 분석 요청을 처리합니다. 제공자를 바꾸면 이전 요청을 취소하고, 실패해도 다른 제공자로 자동 전환하지 않습니다.
- Claude Code·Codex는 설치된 확장에 포함된 실행 엔진과 기존 로그인을 활용합니다. 별도 CLI 설치나 실행 경로 입력이 필요하지 않습니다.
- Claude Code·Codex의 **모델 ID 입력창과 설정을 제거**했습니다. 기본 모델을 바로 사용하며, 이전에 입력한 ID도 무시합니다. Copilot은 계정에서 사용할 수 있는 모델 목록에서 선택합니다.
- 기존 Smart 범위, Copilot 설정과 명령, AI 결과 검증·캐시, 사용자 확인 대상과 중지·재개 기능을 유지합니다. 한국어·영어 설명서도 새 흐름에 맞췄습니다.

설치 후 VS Code를 다시 로드하세요. WSL·SSH에서는 확장이 실행되는 환경에 호환되는 AI 확장이 있어야 합니다. 로그인이나 엔진 호환성 오류가 나면 선택한 확장을 열어 로그인·업데이트 상태를 확인하세요. AI 후보는 실행을 증명하는 호출이 아닌 제안입니다.

This release uses one installed AI extension for Smart Analysis. Auto selects the only installed provider or asks once when several are available. Only the selected provider receives requests; switching cancels the previous request, and failures never trigger another provider.

Claude Code and Codex use their installed extension's bundled engine and cached login. Their model ID inputs/settings are removed: the default model is used automatically. Copilot retains its available-model picker. Existing scopes, validation, caches, manual confirmations and stop/resume behavior remain compatible. Local analysis cache compatibility remains **16**.

The actual installed Codex bundled engine was exercised locally. Claude's live account flow and actual remote Windows/WSL/SSH environments were not available locally; automated tests cover the corresponding discovery/protocol paths. The release workflow verifies unit, memory, performance, Worker and native Extension Host/large-workspace checks on Windows, macOS and Ubuntu. Platform VSIX aliases contain the same universal JavaScript/WASM package.
