# C Relation Explorer 0.1.29

- Select **Callers & Callees** for callers on the left, one selected function in
  the center, and callees on the right. Expand either side independently.
- Right-click Relation to switch **Name order / Source order**. Repeated calls
  stay grouped at the first call location; source order is not execution order.
- Drag the graph background with the left mouse button to pan. Use **Reset graph
  position** in the context menu to return to the initial position.
- Choose **Context layout → Separate** to open **C Relations Context** as an
  independent Explorer view and give Relation the panel's full width. Drag the
  Context view header to move it. Choose **Combined** to restore the existing view.
- Defaults remain name order and Combined. Choices persist in workspace settings.
  Both views share one index, syntax-colored preview and code-click navigation.

## Install

Use **C Relations: Check for Updates → Update**, then **Developer: Reload Window**,
or install the VSIX through **Extensions: Install from VSIX…**. Verify **Context
v0.1.29**. In WSL, install from the WSL-connected VS Code window. The same universal
package supports Windows, macOS and WSL. Offline Help documents all new controls.
