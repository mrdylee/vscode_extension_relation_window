# Dynsight 0.1.89 — AI 설정 전환·모델 복원 수정

- **개별 AI 분석 중에도 설정을 바꿀 수 있습니다.** Smart Analysis: AI의 설정 링크가 기존 분석을 취소하고 종료를 기다린 뒤 확장 → 모델 선택창을 엽니다. 소스 준비·모델 조회 중이던 분석도 뒤늦게 요청을 보내지 않습니다. 선택 중 새 분석은 시작하지 않으며, 대기 중 AI를 끄면 선택창도 열지 않습니다.
- **Copilot 모델의 버전이 바뀌어도 같은 모델 ID를 계속 사용합니다.** 이전 버전의 분석 캐시를 새 버전에 재사용하지 않으며, 새 버전의 결과는 이후 재사용합니다. 선택한 ID 자체가 없어지면 분석을 멈추고 다른 모델로 자동 전환하지 않습니다. 기존 저장 선택도 다시 고를 필요가 없습니다.

**Smart Analysis: AI 하나 → 확장 선택 → 모델 목록 선택** 흐름과, 선택한 제공자 하나만 동작하는 방식은 유지합니다. 문자열·모델 ID 입력은 필요 없습니다. 분석 캐시 호환 버전은 16입니다.

Guided setup can now cancel and await a per-callback analysis from preparation through completion before changing the provider/model. Setup blocks concurrent analysis, and disabling AI while waiting prevents a late picker. Copilot selections resolve by the same model ID after a version update; actual model versions still separate analysis caches. A missing model ID never falls back to another model.

The single AI setting and two native pickers remain. Regression coverage uses controlled provider/model fixtures; live Claude account integration and remote WSL/SSH model catalogs are not verified in the local environment.
