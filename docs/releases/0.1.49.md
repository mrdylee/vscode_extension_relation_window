# Dynsight 0.1.49

Trace a callback from its call site.

1. With **Following selection** active, click `cb` in `cb()` or `callback` in
   `ops->callback()` in the editor or Context.
2. Inspect **Callback targets**, showing possible function names and file/line
   locations. Context previews the original call.
3. Choose a candidate to explore its normal Callers/Callees graph. Pin that
   function if you want to keep exploring it.

Even one target is a static candidate, not proof of runtime execution.
**Other targets may exist** identifies incomplete analysis. Unknown values show
an explicit unresolved message. Candidate selection reuses the index and does
not start additional pointer analysis. **Include Function Arguments** is not
required for this navigation.

Object and array-index selections keep ordinary variable navigation. Stale
candidate choices are rejected when the index changes. Macro-generated indirect
calls remain accessible through the enclosing function's Callees.

Help and README describe the workflow. This navigation update does not change
the inference engine or resolve the separate WSL host/file-count investigation.
