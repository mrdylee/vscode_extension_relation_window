# C Relation Explorer 0.1.11

고정 해제 상태의 자동 선택 추적을 수정한 버전입니다.

- 함수·변수 이름을 더블클릭해 선택해도 관계가 갱신됩니다.
- 분석 중 선택을 놓친 경우 분석 결과가 들어오면 다시 추적합니다.
- 고정 중 다른 코드 창으로 이동했다면 고정 해제 시 그 창의 선택을 반영합니다.
- 같은 심볼 안에서 커서를 움직일 때는 관계 트리를 다시 만들거나 전송하지 않습니다.

## 다운로드와 설치

- [Windows VSIX](https://github.com/mrdylee/vscode_extension_relation_window/releases/download/v0.1.11/c-relation-explorer-0.1.11-windows.vsix)
- [macOS VSIX](https://github.com/mrdylee/vscode_extension_relation_window/releases/download/v0.1.11/c-relation-explorer-0.1.11-macos.vsix)
- [WSL VSIX](https://github.com/mrdylee/vscode_extension_relation_window/releases/download/v0.1.11/c-relation-explorer-0.1.11-wsl.vsix)

기존 설치에서는 **C Relations: Check for Updates**를 실행하거나, 파일을 받은 뒤 **Extensions: Install from VSIX…**로 설치합니다. WSL에서는 WSL에 연결된 창에서 설치하고 확장 목록의 WSL 영역에 설치됐는지 확인하세요. 설치 후 창을 다시 로드하고 Context 왼쪽의 버전이 **0.1.11**인지 확인하세요.

세 파일과 접미사 없는 공통 업데이트 파일은 동일한 JavaScript/WASM 범용 패키지입니다. `SHA256SUMS.txt`를 함께 제공합니다.

## 검증과 제한

- 게시 전 Windows/macOS/Ubuntu의 단위·Extension Host 테스트가 통과해야 합니다.
- macOS FreeRTOS 655개 파일, 3단계에서 네 심볼의 선택 이벤트부터 관계 상태 반영까지 104~108ms를 측정했습니다. WSL의 화면 표시 시간까지 측정한 값은 아닙니다.
- WSL 실제 원격 연결 및 원격 자동 설치는 아직 실환경 미검증입니다. 자동 설치에 문제가 있으면 위 WSL 파일로 설치하세요.
- `File exceeds the 2,000,000 character analysis limit`는 한 파일이 분석 크기 제한을 넘었다는 안내입니다. 해당 파일은 제외되며 다른 파일은 계속 분석합니다. Polyspace 등에서 생성한 큰 파일도 이 제한에 해당할 수 있습니다. 이번 버전은 크기 제한을 바꾸지 않습니다.
