# Dynsight 0.1.100

Salgu now plays one of **20 animated scenes** in the Relation panel. Each
appearance draws a new random **10–20-second interval**, measured from the
start of the previous appearance. Keep Relation visible and VS Code focused.

Clicking a function name directly in the Relation graph stops the current
scene and starts a fresh random wait. Wheel scrolling, dragging, variable
selection, and graph refreshes from work in the main editor preserve the
running timer.

The ten new everyday scenes show yawning, dozing, curled-up naps, stretching,
paw grooming, ear scratching, drinking, head tilts, tail wags, and rolling
onto the back. The watching scene now blinks, and breathing stays anchored
to the sill. The scenes share one sprite image and respect reduced motion.

Run **Dynsight: Check for Updates** or install the VSIX for your platform in
VS Code. The Windows, macOS, and WSL downloads contain the same extension.
