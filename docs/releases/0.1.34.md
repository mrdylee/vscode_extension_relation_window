# C Relation Explorer 0.1.34

- Protect macro/callback postprocessing with Worker heap headroom. Memory-limited
  results show **Partial index: memory budget reached** with Analysis notices.
- Keep directly written function arguments, such as `svc_send_event(...,
  priv_mode_change)`, as incomplete candidates when preprocessing is limited.
  **Settings → Include Function Arguments** must be on (default off).
- An actual Worker out-of-memory error shows **Analysis stopped**, never a false
  **Index ready**. Narrow **Include / Exclude**, then **Rebuild index** to start a
  fresh Worker. An older installed version needs **Developer: Reload Window**.
- No automatic folder exclusions or heap-limit increase. Very large individual
  allocations, system memory and WASM allocations remain practical limits.

Windows, macOS and WSL downloads contain the same universal VSIX. In WSL, install
the extension in the WSL extension host. The small-heap stress case is verified
locally; the user's private WSL project still requires confirmation.
