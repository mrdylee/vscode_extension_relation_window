# Dynsight 0.1.97

Editing a C/H file keeps its symbols and direct references current without
restarting project analysis. Automatic macro/callback updates now accumulate
changes and run **one hour after the last actual source change**. Further edits
postpone the batch; duplicate save/watch notifications do not. Saving alone
does not start an immediate deep pass.

**Relations pending** shows the changed-file count. Use **Update now** or
**Dynsight: Resume Local Analysis** to update affected relationships immediately
while reusing parsed source. Save all modified C/H files in scope first. Pending
files and their deadline survive restart when workspace storage is available;
initial indexing, explicit Rebuild index and deliberate analysis setting changes
retain their existing behavior.

Saved batches reuse unrelated results, build-specific index entries and cache
records. Common headers provide reusable declaration context, while actual
function/global flow and generated macro names connect affected analysis. Shared
header changes still update their dependents. Review fixes retain the latest
deadline when older reads finish late, preserve restored unsaved-editor waits,
and avoid delaying an unchanged selected-build cache after edits were discarded.

Analysis-cache compatibility remains **19**. Compatible caches do not require
rebuilding solely because of this extension update. Downloads for Windows,
macOS and WSL contain the same JavaScript/WASM extension.
