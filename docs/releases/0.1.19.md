# C Relation Explorer 0.1.19

- Fix missing files when Include combines brace patterns (for example `App/**/*.{c,h}`) with other patterns (`Drivers/**`). Search patterns independently and deduplicate before the initial file limit. Folder names containing literal commas also work consistently across indexing and file changes.
- Includes the unreleased 0.1.17–0.1.18 improvements: stable depth menus during updates, click-to-expand at the selected depth, original double-click target preservation, and folder-scoped Include/Exclude settings.
- Include is empty by default (all C/H files). Exclude always wins. Changes automatically rebuild the index. See README for Settings UI and JSON examples.

Download the Windows, macOS or WSL VSIX and use **Extensions: Install from VSIX…**, then **Developer: Reload Window**. Verify **Context v0.1.19**. The platform-labelled files contain the same universal package. For WSL, install into the WSL-connected VS Code window. Existing installations can use **C Relations: Check for Updates** once this release is published.
