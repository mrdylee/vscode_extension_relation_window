# C Relation Explorer 0.1.14

The extension interface is now in English, including toolbar controls, symbol details, navigation hints, accessibility labels, dialogs, and update notifications.

- **Following selection**: Relation follows the symbol selected in the main editor or Context. Click to pin.
- **Pinned · Follow paused**: Relation keeps its current root. Click to resume following selection.
- **Skip inactive branches**: excludes branches disabled by literal `#if` / `#elif` values of 0 or 1. The tooltip explains the limits.

Conditional analysis is unchanged. `#ifdef`, `#ifndef`, and `defined(...)` conditions remain unresolved, with both branches retained. Source `#define` / `#undef`, included headers, and build definitions are not used to evaluate these conditions.
