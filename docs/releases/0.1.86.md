# Dynsight 0.1.86 — 한국어 / English user guides

Relation 상단의 **Help · 사용법**에서 한국어·영어 설명서를 열 수 있습니다.
VS Code 표시 언어에 맞춰 처음 열리며, 문서 맨 위에서 언어를 바꿀 수 있습니다.

- 처음 사용자를 위한 빠른 시작과 클릭 순서대로 따라 하는 Settings 안내
- Include/Exclude, Smart Analysis, 화면 배치, Copilot 설정의 예시와 기본값 표
- 슬롯·잠금·Backspace, 아이콘, 빌드 설정, 문제 해결과 업데이트 안내
- Settings 맨 위의 한국어·영어 사용법 링크와 언어별 명령 팔레트 명령

설명서는 VSIX에 포함되므로 인터넷 없이 읽을 수 있습니다. 설명서를 열어도
현재 Relation 트리, 선택, Context와 되돌리기 상태를 유지합니다.

The extension now bundles separate Korean and English offline manuals. Use
**Help · 사용법** in Relation or **Dynsight: Open User Guide**. Explicit commands
**Dynsight: 사용 설명서 열기 (한국어)** and **Dynsight: Open User Guide (English)**
open a specific language. Both guides provide quick start, settings walkthroughs,
all visible settings and defaults, examples and troubleshooting. The existing
English detailed reference is retained.

Analysis cache compatibility remains 16; this help update does not change analysis
behavior. Install the Windows/macOS/WSL VSIX for your environment and reload VS Code.
