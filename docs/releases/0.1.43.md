# Dynsight 0.1.43

C Relation Explorer is now **Dynsight — C Code Explorer**.

The extension list uses the full name; panels, toolbar, commands, diagnostics,
update notifications and issue reports use **Dynsight**. README and offline Help
now use the new name.

Existing installations update in place. The extension ID, publisher, settings,
command/view IDs, repository and VSIX filename convention are unchanged. Your
Include/Exclude preferences, keybindings and saved layout remain compatible.
Some generated Settings labels still show **C Relation** because their keys remain
`cRelation.*`. Analysis behavior and memory limits are unchanged in this release.

Install the Windows, macOS or WSL VSIX and reload VS Code. Look for **Dynsight
v0.1.43** in the toolbar. In WSL, install into the WSL extension host.
