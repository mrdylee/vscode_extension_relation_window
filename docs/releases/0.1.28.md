# C Relation Explorer 0.1.28

- Follow calls hidden behind supported C macros, including nested expansion,
  argument substitution, token pasting, stringizing and variadics. Inspect the
  expansion chain and effective code while navigating the original invocation.
- Infer possible callback/function-pointer targets from assignments, forwarding,
  registration, returns and named struct/array tables. Keep known instances and
  constant indices separate. Use the existing Callees/Callers/References modes.
- Inferred edges use the existing dashed candidate icons. Their popup shows
  evidence locations; click to preview in Context, Enter/double-click to open.
  Target functions can expand their outgoing calls. No additional window is needed.
- Preserve unknown targets and expose analysis limits. Inference is static and
  bounded, not proof of runtime execution. Additional callback inference has an
  approximately 10-second budget; narrow Include/Exclude when notices indicate
  partial results. Integer address round-trips, arbitrary byte operations and
  compiler-specific preprocessing can remain unresolved. See bundled Help.
- Keep expensive work and internal flow facts in the Worker. Reuse equivalent
  expansions, indexed object/array slots, type lookups and unchanged summaries.

Both features received separate review-work passes, fixes and regression tests.
Reviewed development checkpoints use annotated checkpoint tags; main remains at
v0.1.24 and previous version tags/releases remain available for rollback.

Use **C Relations: Check for Updates** → **Update** → **Reload Window** and verify
**Context v0.1.28**, or use **Extensions: Install from VSIX…**. In WSL, install
into the WSL-connected window. The Windows, macOS, WSL and unlabelled downloads
contain the same universal VSIX.
