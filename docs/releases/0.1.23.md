# C Relation Explorer 0.1.23

- Relation details now appear after **500 ms** with the pointer stationary, instead of one second.
- Moving the pointer restarts the delay; leaving the node cancels it. Keyboard access with Space is unchanged.

Use **C Relations: Check for Updates** and approve **Update**, then **Reload Window**. Alternatively, install the Windows, macOS or WSL VSIX with **Extensions: Install from VSIX…**. Verify **Context v0.1.23**. WSL users should install into their WSL-connected window. All platform downloads contain the same universal package.
