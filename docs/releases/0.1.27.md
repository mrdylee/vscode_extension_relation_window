# C Relation Explorer 0.1.27

- Fix missing member relationships when a local `struct T *p` declaration introduces a tag that is defined later in the same block. Keep visible outer types separate.
- Fix missing outer candidates when an unknown `#if` condition controls a shadowing local variable. Nested scopes, callback names and block extern declarations retain possible targets.
- Keep v0.1.26's compact member navigation, icons, access filters and build-free workflow.

This patch addresses the two review findings from v0.1.26. Existing analysis limits, including unresolved runtime pointer targets, macro expansion and casts, still apply; see **Help**.

Use **C Relations: Check for Updates** → **Update** → **Reload Window** and verify **Context v0.1.27**, or install a VSIX with **Extensions: Install from VSIX…**. WSL users should install into their WSL-connected window. The Windows, macOS, WSL and unlabelled downloads contain the same universal package.

Released from `feature/c-analysis-navigation`; main remains at v0.1.24. Previous releases remain available for rollback.
