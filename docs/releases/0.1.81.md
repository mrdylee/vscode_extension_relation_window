# Dynsight 0.1.81 — Tree-sitter Make build contexts

Makefile and included `.mk` statements now use Tree-sitter Make. Supported
assignments, conditionals, includes and rules retain original source locations
and feed the existing bounded build evaluator for C projects using GCC or Diab.

- Correct quoted conditions and command-line variable precedence in define blocks.
- Resolve computed variable references and scoped, bounded foreach expressions.
- Preserve BAT/SH entry discovery, generated metadata overlays, ordered explicit
  defines/undefines, include paths and per-source build contexts.
- Bundle the grammar and runtime. A minimal pinned grammar patch supports empty
  substitution replacements such as `$(DIRS:/=)`.

Install the matching Windows/macOS/WSL VSIX and reload. Existing build selections
can be refreshed with **Dynsight: Refresh Build Configuration**. Analysis cache
compatibility advances to 15, so stale cached facts rebuild.

This remains static analysis: scripts, Make and compilers are not executed.
Unsupported dynamic operations, compiler defaults, Diab-specific semantics and
final link coverage retain uncertainty. The private firmware was not available;
validation covers synthetic GCC/Diab contexts and extension runtime checks.
