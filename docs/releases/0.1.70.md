# Dynsight 0.1.70 — Local analysis Stop and per-function progress

## Local callback analysis

- Remove the project-wide 10-second cutoff. No total time-budget setting is added.
  Memory, work, slot and convergence protections remain in place.
- Show the current function's elapsed analysis time and reset it at the next
  visit. Visits lasting at least five seconds show **Taking longer**; this is an
  indication only and does not automatically stop analysis. It measures static
  analysis, not the runtime of a callback.
- Use **Stop local** to interrupt callback propagation, macro expansion or final
  registration-candidate collection. Keep discovered results and mark the index
  partial. Ordinary source edits do not automatically resume a manually paused
  pass.
- Use **Retry local** to retry relationships using parsed sources. These actions
  are also available as **Dynsight: Stop Local Analysis / Resume Local Analysis**
  in the command palette. They do not enable Copilot.
- Distinguish manual cancellation from the removed time-budget condition. Keep
  already collected registration facts without caching partial output as complete.

## Cache migration

Analysis compatibility remains version 3. Old fixed-deadline caches reuse parsed
sources and automatically recompute relationships once under the new policy.
No manual Rebuild is required for a valid 0.1.69 index. Cancelled and transiently
limited generations are not accepted as completed derived caches.

This release addresses analysis control and diagnostics. The separate conditional
preprocessor parsing findings in analysis.md remain outside this change. Original
firmware sources were unavailable for performance verification.
