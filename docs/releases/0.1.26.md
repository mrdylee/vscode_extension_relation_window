# C Relation Explorer 0.1.26

- Select a named struct/union field at its declaration or use to navigate **Motor.state** independently of **Sensor.state** and a global **state**.
- Reuse the existing R/W/RW/& filters, exact source previews and caller expansion. Keep compact nodes and icons; details identify the owning type.
- Resolve declared variable/parameter types, typedef and pointer aliases, named nested fields, arrays/dereference, unions and bit fields, with scoped types and indexed transitive headers.
- Keep ambiguous conditional/header definitions as candidates. Unknown receivers are not connected by field name alone.
- Include usage examples and limits in the offline **Help** guide.

This is declared-type analysis without a build. It does not infer runtime pointer targets, expand macros, resolve cast/function-return receivers, promote anonymous members or collect designated-initializer member references. Writes through pointer fields or to array elements do not count as writes to the whole field. Type/expression traversal is bounded to 32 steps and intermediate candidates to 64.

Use **C Relations: Check for Updates** → **Update** → **Reload Window**, or install a VSIX with **Extensions: Install from VSIX…**. Verify **Context v0.1.26**. In WSL, install into the WSL-connected window. Windows, macOS and WSL downloads contain the same universal package; the unlabelled VSIX is used by the updater.

Released from `feature/c-analysis-navigation`; `main` remains at v0.1.24. To return to the previous Callees version, reinstall a [v0.1.25 VSIX](https://github.com/mrdylee/vscode_extension_relation_window/releases/tag/v0.1.25) and reload the window.
