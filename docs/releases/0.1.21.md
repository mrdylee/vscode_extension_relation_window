# C Relation Explorer 0.1.21

- Function declarations use a blue outlined document; definitions use a purple filled cube. Icons remain 16×16 with no extra text in the graph.
- Details and accessible labels identify **Function declaration** and **Function definition**. Dashed outlines still mark conditional/candidate/recursive states independently.
- Includes the **Settings** and offline **Help** toolbar buttons introduced in 0.1.20.

Install the Windows, macOS or WSL VSIX using **Extensions: Install from VSIX…**, then **Developer: Reload Window**. Verify **Context v0.1.21**. All three downloads contain the same universal package. In WSL, install into the WSL-connected window.
