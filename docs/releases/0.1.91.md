# Dynsight 0.1.91 — 부분 분석 정확성과 Makefile 해석

- **불완전한 콜백을 완전한 결과로 표시하던 문제를 수정했습니다.** 매크로 후보가 잘리거나 설정 함수의 분석이 작업 한도로 중단되면, 관련 값과 호출자에 누락 가능성을 전달합니다. 이미 확인한 후보는 유지합니다.
- **Makefile 정적 해석을 보완했습니다.** 하위 Makefile의 작업 폴더, 변수·대상 이름 조합, 바깥쪽 `eval(call …)` 모듈 include, `MAKEFILE_LIST`, 단순 wildcard 소스 목록을 처리합니다. 공통 대상별 옵션을 재사용해 기존 작업 한도를 유지합니다. Make·컴파일러·생성기를 실행하지 않습니다.
- **상태 안내를 구분합니다.** 고정 한도는 `Local analysis limited / Re-run local`, 중단은 `Retry local`, 일시정지는 `Resume local`로 표시합니다. `No build selected · N found`는 후보를 찾았지만 아직 빌드를 적용하지 않았다는 뜻입니다.

**업데이트 후 Rebuild index를 실행하세요.** 분석 캐시 호환 버전이16에서17로 변경됐습니다. 100,000회 함수 작업량,256개 저장 위치/영역,32개 매크로 대안 한도는 유지합니다. 이 업데이트가 모든 관계를 완전히 해결하거나 기존 WSL 메모리 문제를 해결한다는 뜻은 아닙니다.

실제 RBMS Makefile의 컴파일 명령을 추출해 검증했습니다. Diab 전용 옵션, 컴파일러 기본 매크로·헤더, 생성 파일과 최종 링크 포함 여부를 완전히 확인하지 못한 구성은 계속 `partial`로 표시하며 미검증 옵션으로 분기를 제거하지 않습니다. 빌드 선택과 Include/Exclude, AI 제공자·모델은 자동 변경하지 않습니다.

업데이트: **Dynsight: Check for Updates** 또는 아래 VSIX를 **Extensions: Install from VSIX…**로 설치한 뒤 **Developer: Reload Window**, **Rebuild index**를 실행하세요. WSL에서는 연결된 VS Code 창에 설치합니다.

Callback results now retain explicit uncertainty after macro truncation or omitted helper writes. Static Make extraction handles nested working directories, computed names/targets, bounded outer eval-call includes, Makefile lists and simple wildcard sources without executing build tools. Shared target options reuse work within existing bounds. Fixed limits, interruption, pause and unselected build discovery have distinct guidance. Cache compatibility17 requires Rebuild index; unsupported compiler and generated-input semantics remain partial.
