# Dynsight 0.1.67 — Windows / macOS / WSL

## AI callback scope

- **Settings → Copilot Include** is an editable JSON array. Initial setup copies
  general Include paths; delete paths that should not use AI. New general Include
  paths are copied without restoring previous AI removals. Empty AI Include means
  no AI requests. Copilot Exclude takes priority.
- Explicit AI arrays win when both Include lists are edited in the same JSON
  save. Scope changes cancel active analysis and restore eligible cached results
  without starting new paid requests. Use Analyze for missing results.
- Scope applies to callback invocation files. Supporting evidence may still come
  from other locally indexed files. General Include/Exclude controls local indexing.
- Stop or disabling Copilot also cancels pending Analyze commands during initial
  Include setup, model discovery or model selection.

## Relation and Combined layout

- Available AI candidates replace indirect/unresolved callback entries at the
  same invocation. AI confirmation of partial local targets does not duplicate
  caller/callee counts. Original local records remain available for cursor
  tracing and restoration when AI is cleared. AI suggestions remain uncertain.
- Combined layout can preserve the left sidebar, right sidebar or both sidebars
  at full height. Existing full-width and Separate choices remain available.
  Explicit alignment also affects other bottom-panel views, such as Terminal.

## Index compatibility

Compatible local indexes can be reused across extension updates. Diagnostics
distinguishes incompatible analysis formats or settings from damaged cache files.
Existing unversioned caches need one manual **Rebuild Index** on this upgrade.
This release does not change the callback propagation limits or the separate
typedef/memory-model issues investigated in analysis.md.

## Downloads

Install the file for your environment and reload VS Code:

- Windows: `dynsight-0.1.67-windows.vsix`
- macOS: `dynsight-0.1.67-macos.vsix`
- WSL: `dynsight-0.1.67-wsl.vsix`, installed in the WSL extension host

These files and the common/legacy updater filenames contain the same universal
JavaScript/WASM package. SHA256SUMS.txt lists checksums. Release CI tests Windows,
macOS and Ubuntu; live WSL remote installation is not verified here.
