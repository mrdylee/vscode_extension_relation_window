# C Relation Explorer 0.1.40

Report problems from the extension with an editable diagnostic draft.

- Open **Diagnostics → Report issue**, or **C Relations: Report Issue** from the
  Command Palette if the Relation panel is unavailable.
- Review the report and describe the symptom and reproduction steps. Choose
  **Copy & Open GitHub**, paste into the issue, and submit it yourself.
- Reports include version/environment, view options, scope counts, categorized
  notices and the latest memory checkpoints. They omit source, symbols, paths,
  raw errors and actual scope patterns. Review anything you add: issues are public.
- Reporting works from the last snapshot even with a busy/stopped Worker and
  does not rebuild the index. **Copy report** and **Save As** support offline use.

No telemetry service or automatic issue submission is added. GitHub sign-in is
required to submit an issue. Save-only indexing is not part of this release.

Install the VSIX for your environment, reload VS Code and confirm **v0.1.40** in
the Relation toolbar. In WSL, install into the WSL extension host.
