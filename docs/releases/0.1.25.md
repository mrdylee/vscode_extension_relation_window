# C Relation Explorer 0.1.25

- Add **Callees · Called functions** to the existing Relation selector. Follow outgoing calls using the same depth controls and compact graph.
- Group repeated calls into one node while retaining every actual call location in the details popup. Clicking a Callees child previews its call site in Context; Enter or double-click opens that site in the editor.
- Show macro invocations, indirect expressions and unresolved calls as explicitly described leaves. Macro expansion and runtime function-pointer target inference are not implemented in this release.
- Preserve variable Read/Write filters and incoming caller navigation when switching between variables and functions.
- Keep the original icons, 500 ms stationary hover, incremental indexing, and build-free source-folder workflow.

Use **C Relations: Check for Updates** → **Update** → **Reload Window**, or install a VSIX with **Extensions: Install from VSIX…**. Verify **Context v0.1.25**. WSL users should install into their WSL-connected window. Windows, macOS and WSL downloads contain the same universal package; the unlabelled VSIX is used by the updater.

This release comes from `feature/c-analysis-navigation`; `main` remains at v0.1.24. To revert the installed extension, reinstall a [v0.1.24 VSIX](https://github.com/mrdylee/vscode_extension_relation_window/releases/tag/v0.1.24) and reload the window.
