# Dynsight 0.1.54 — Persistent index and optional Copilot callbacks

Reopening an unchanged workspace restores the saved index without reparsing source
or rerunning relation analysis. Changed files are reparsed and dependent relations
are refreshed. Common headers and token-pasting macros can connect many files, so
an edit can still require broad relation analysis. Unsaved changes stay temporary.
Use **Rebuild index** for a full local rebuild or an incompatible/damaged cache.

Optional **Copilot Callbacks** uses the GitHub Copilot account already available in
VS Code. In **Settings → Copilot Model**, choose **Select Copilot Model** to list
available models. Selection alone does not enable analysis or send source.
Run **Dynsight: Analyze Callbacks with Copilot** to enable it and grant access.
Relevant source snippets are sent to Copilot; account usage and policies apply.

AI results appear as **AI candidate** in Callers, Callees and both mode with source
evidence. These are suggestions, not proven runtime calls. Responses are restricted
to locally indexed targets and evidence. Outstanding work is canceled when inputs
or model selection change. Model-specific caches avoid paying again for unchanged
results; startup, navigation and normal Rebuild never initiate AI requests.
Saved edits and explicit analysis commands request at most five uncached callback
analyses per batch. **Reanalyze Callback Candidates with Copilot** explicitly
invalidates current AI results. AI is off by default.

The static callback engine remains independently configurable. This release fixes
missing wildcard-write dependencies and reduces array-region lookup work without
raising the existing analysis limits. Static analysis off skips pointer propagation
and callback-only macro initializer expansion. Shared source facts needed by
function-argument navigation are retained; Copilot is not a replacement for them.

Diagnostics and Report Issue include disk-cache and AI activity counters. Local
index records contain source/analysis data in workspace extension storage. AI cache
records contain validated result identifiers and hashes, not source prompts.

The private WSL firmware and a live paid Copilot account have not been exercised
in this development environment. Mocked LM tests verify cache, consent denial,
model switching and cancellation; installed VS Code tests cover local operation.
