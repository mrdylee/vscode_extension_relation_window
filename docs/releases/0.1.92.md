# Dynsight 0.1.92

Fixes the actual RBMS `Partial index: analysis limits reached` case while preserving its 147-file analysis scope.

- Recognize a header's guarded prefix even when more directives follow the guard. Expand the prefix once and still process the unguarded suffix on each include.
- Separate macro and callback function work accounting: each phase keeps its cumulative 100,000-operation allowance. Macro scans no longer exhaust the following callback phase's allowance.
- Retain up to 1,024 callback mutation slots and reachable regions during workspace analysis. The measured RBMS summaries require up to 686 exact effects. Heap protection, cancellation, work limits and conservative omitted-effect reporting remain active.
- Preserve detailed source relations when an incomplete selected build has no usable translation units. Such a build no longer replaces the 147-file view with an empty `Index ready` result.

Analysis cache version is now 18. Use **Rebuild Index** after upgrading an existing cache.

The actual RBMS workspace completes local indexing both without a selected build and with `Build_RBMS.bat`. Its unsupported Diab options and pre-build generators still leave build configuration coverage unverified; this fix uses the full source fallback. Existing syntax and unresolved-call notices remain visible. It does not execute BAT files, compilers, generators or AI requests.
