# Dynsight 0.1.45

Investigate unexpected reindexing even when Analysis notices is empty.

- **Diagnostics → Last rebuild** shows the start time and trigger: extension
  startup, analysis-setting change, workspace-folder change, command or button.
- **Rebuild history and source activity** shows the last five rebuilds, outcomes,
  durations, session parse/relation-pass counters and the latest source event.
- **Report issue** includes a sanitized summary with setting names only, without
  source, symbols, paths or configuration values. Nothing is automatically uploaded.

If the problem recurs, capture Diagnostics before manually rebuilding or reloading.
A source event does not necessarily mean another parse; unchanged content is reused.
History resets when the extension starts again. This is a diagnostic release:
it does not claim the reported restart or macro-selection problem is fixed.

Install the Windows, macOS or WSL VSIX and reload VS Code. Confirm **v0.1.45**.
From v0.1.44 this updates `dylee.dynsight` in place. Older installations still need
the one-time previous-extension removal/reload described in Help.
