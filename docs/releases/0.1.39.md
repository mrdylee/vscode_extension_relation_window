# C Relation Explorer 0.1.39

Reduce memory overhead during callback analysis and repeated index rebuilds.

- Rebuild Index releases the analyzer's previous macro and callback caches.
- Callback project caching follows the analyzer lifetime instead of retaining
  historical projects through their first source file.
- Removing function bodies also removes their obsolete macro cache.
- Empty/unchanged callback values share immutable containers; local writes no
  longer copy the entire local-variable table for each assignment.
- Existing call sites, callback-passing relationships, ambiguity evidence and
  analysis limits are preserved. The memory guard remains at 60% of Worker JS
  heap capacity. This update does not increase RAM limits or narrow analysis scope.

If your project still reports Partial index, open Diagnostics and photograph the
whole panel before rebuilding. Local validation does not establish the memory
requirements of every WSL project.

Install the VSIX for your environment, reload VS Code, and confirm **v0.1.39** in
the Relation toolbar. In WSL, install into the WSL extension host.
