# Dynsight 0.1.101

Use **Dynsight: Select Build Configuration** to select a `compile_commands.json` from your current build. Dynsight reads the recorded C compiler arguments and response files without running the commands. It keeps multiple configurations for a source file. Files missing from a partial database keep their **unknown** build membership.

This release preserves quoted string macros in Windows command lines and handles literal `%`, `?`, and `#` in build paths. C callback analysis now follows the shared body and trailing `else` when preprocessor branches select different `if` headers, including literal `#elif` conditions and callbacks declared inside the shared block. Initializer macro expansion now considers up to 64 alternatives; function bodies retain their limit of 32.

Run **Dynsight: Check for Updates** or install the VSIX for Windows, macOS, or WSL. After updating, run **Dynsight: Rebuild Index** to regenerate your saved index for analysis cache version 21.
