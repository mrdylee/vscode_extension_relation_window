# Dynsight 0.1.90 — Markdown 미리보기 선택

- **Help의 기본값이 읽기 전용 텍스트로 바뀝니다.** 도움말을 열 때 내장 Markdown 미리보기나 언어 기능을 호출하지 않습니다. 한국어·영어 선택과 현재 Relation 상태는 유지합니다.
- **Settings → Markdown Preview** 드롭다운 하나에서 **Disabled (read-only text)** 또는 **Markdown Preview Enhanced**를 선택할 수 있습니다. Enhanced가 없거나 비활성화되어 있으면 설치·활성화할 확장 화면을 안내합니다. 미리보기를 사용할 수 없으면 텍스트 도움말을 표시합니다.
- 같은 설정에 **Manage built-in Markdown…** 및 **Install or enable Markdown Preview Enhanced…** 링크를 제공합니다. 내장 Markdown Language Features를 이 프로젝트에서 끄려면 관리 화면에서 **Disable (Workspace)**를 직접 누르고 **Restart Extensions**가 표시되면 적용하세요. **Markdown Language Basics**는 켜두세요.

**Dynsight 설정만으로 다른 확장이 비활성화되지는 않습니다.** 실제 비활성화는 VS Code에서 한 번 직접 해야 합니다. 이 설정은 Dynsight 도움말 표시 방식만 선택하며 일반 Markdown 단축키를 바꾸지 않습니다. Enhanced는 자동 설치하지 않습니다.

업데이트: **Dynsight: Check for Updates**에서 업데이트한 뒤 **Developer: Reload Window**를 실행하거나, 아래 VSIX를 **Extensions: Install from VSIX…**로 설치하세요. WSL에서는 연결된 VS Code 창에서 설치합니다.

Dynsight Help now defaults to read-only plain text. One Markdown Preview setting optionally routes localized guides to Markdown Preview Enhanced, with a readable text fallback. Native extension-management links guide manual workspace disabling of built-in Markdown Language Features and installation/enabling of Enhanced. The preference does not modify other extensions' enablement or general Markdown shortcuts.

Large-workspace Enhanced memory performance and the previously reported WSL memory issue are not claimed resolved by this guide-rendering change. Analysis behavior and cache compatibility 16 are unchanged.
