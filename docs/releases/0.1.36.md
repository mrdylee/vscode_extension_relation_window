# C Relation Explorer 0.1.36

- **Settings → Macro Expansion Folders → Select folders…** lets you check which
  indexed source folders need macro expansion. The Command Palette also provides
  **C Relations: Select Macro Expansion Folders**. Include patterns become choices;
  with empty Include, choose top-level folders or root C/H files. Custom glob
  patterns and per-folder settings in multi-root workspaces are supported.
- The default `["**"]` expands all indexed sources. Clear every checkbox to disable
  expansion; cancel leaves settings unchanged. Changes automatically rebuild the
  index. Unchecked sources keep basic analysis, including direct calls, literal
  function arguments and supported pointer inference. Their indexed headers still
  supply macro definitions to checked sources. Include/Exclude keeps controlling
  the basic file scope, and Exclude takes priority.
- Macro-dependent calls or callback targets may be absent in unchecked sources.
  This reduces macro processing; basic indexing and pointer analysis still consume
  memory, so it does not guarantee that every project fits the Worker budget.
- **↩ Pin** beside **Pinned · Follow paused** returns the main editor and Context
  to the pinned symbol and reveals its root in Relation, preserving the pin,
  expanded branches and traversal settings.
- Updated the offline Help and README with examples and usage instructions.

Windows, macOS and WSL downloads contain the same universal VSIX. In WSL, install
in the WSL extension host. After updating, use **Developer: Reload Window** and
confirm **C Relations v0.1.36** in the toolbar. Use **C Relations: Check for Updates**
to check immediately; automatic checks follow the existing daily schedule.
