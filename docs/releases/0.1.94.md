# Dynsight 0.1.94

Improves static Diab/RBMS build-context extraction. Dynsight recognizes the explicit Diab 5.9.6.7 option forms observed in RBMS general, MCAL, SafeRTOS and SOX Makefiles, preserving ordered defines and include paths for C analysis.

Overlapping object patterns now select the appropriate source path. Nested targets retain their directories, empty implicit-rule stems are rejected, and declared generated-source prerequisites participate in rule selection. Compiler option values ending in `.c` no longer become source files, and multi-source commands retain a separate bounded context per C input.

Build metadata refreshes correctly after folder changes and Windows URI spelling changes. Unresolved target-specific option appends remain partial. The updated extraction fingerprint refreshes earlier build contexts. The panel also includes the previously prepared D-shaped call-graph icon.

Regression coverage includes cold/warm analysis, edited configurations, callback selection, competing rules, generated prerequisites and metadata invalidation. Read-only checks of the RBMS app target retain 223 C commands with existing source paths and supported explicit options.

Build context remains static evidence: compiler builtins and default includes are unknown, generators are not executed, and the full root BAT projection can still report extraction limits and unknown membership. Native Diab and hardware behavior are not established by these checks. Downloads for Windows, macOS and WSL contain the same JavaScript/WASM extension.
