# C Relation Explorer 0.1.20

- **Settings** in the C Relations toolbar opens Include/Exclude settings for the current workspace. Without a folder it opens user settings.
- **Help** opens a bundled offline user guide inside VS Code. No Git or GitHub account is required to read navigation instructions, Include/Exclude examples, inactive-branch behavior, troubleshooting and WSL guidance.
- Command Palette: **C Relations: Configure Analysis Scope** and **C Relations: Open User Guide**. Both actions preserve the current Relation root.

Install the Windows, macOS or WSL VSIX using **Extensions: Install from VSIX…**, then **Developer: Reload Window**. Verify **Context v0.1.20**. All three downloads contain the same universal package. In WSL, install into the WSL-connected window. Existing users can use **C Relations: Check for Updates** once this release is published.
