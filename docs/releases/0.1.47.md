# Dynsight 0.1.47

File read/analysis failures now show **Partial index** instead of **Index ready**.

Diagnostics shows where file counts changed:

- **Search results**: results returned by file search; may include duplicates or
  non-C files.
- **Selected**: unique C/H files within the configured scope and file limit.
- **Indexed / Failed / Unaccounted**: selected-file results at rebuild end.
- **Discovery: unfinished**: search stopped on an error or file limit.

The last five rebuilds retain these counts. They are included in **Report issue**
and persistent history without file paths. Later source changes can alter the
current file count; search counts do not establish that every file was found.

Install the VSIX and reload, then run **Rebuild index**. If the count is unexpectedly
small, use **Diagnostics → Report issue → Save report** to share the stage counts.
The reported 1,820-to-297 decrease and Extension Host restart are still under
investigation; this release fixes misleading status and adds evidence.
