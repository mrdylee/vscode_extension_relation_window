# C Relation Explorer 0.1.17

- Fix depth menus disappearing when background index or preview updates arrive. Relation-mode menus and unchanged definition choices also remain mounted.
- Click a Relation symbol to update Context and expand from that node using the toolbar depth: one level with `1 level`, two with `2 levels`. The original root, other branches and existing deeper expansion are preserved. Repeated clicks do not toggle or expand indefinitely.
- Double-click/Enter opens source; popup call-site clicks still preview the exact location. Cycle detection and the 300-node limit remain in effect.

## Install

Download the Windows, macOS or WSL VSIX and use **Extensions: Install from VSIX…**, then **Developer: Reload Window**. Verify **Context v0.1.17**. The platform-labelled files contain the same universal package. In WSL, install into the WSL-connected VS Code window. Existing installations can use **C Relations: Check for Updates** after this release is published.
