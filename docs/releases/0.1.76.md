## Changes

- Ordinary numeric conditions and data-only array reads no longer create
  unnecessary callback dependency roots. Actual callback selectors, pointer
  aliases, conditional side effects and uncertain types remain tracked.
- Conditional member-type inspection avoids repeatedly visiting the same cached
  layout. Region analysis reuses immutable path syntax within one run, skips
  empty lookups and duplicate registrations, and retains symbolic/byte-range
  invalidation. Callback candidates and the existing 256/64 limits are preserved.
- Diagnostics distinguish blocked source preparation from work in progress.
  Current results with failed sources, file-count limits or stopped Workers
  remain visibly partial instead of appearing complete.
- Saved analysis compatibility is **9**. Older analysis caches need rebuilding;
  user-confirmed callbacks remain stored separately.

## Verification and limits

Regression and differential tests cover candidate identity, original locations,
conditions, evidence, uncertainty, disk restoration and actual protection limits.
The release workflow retains Windows, macOS and Ubuntu verification gates.
Ubuntu CI is not an installation into a user's WSL environment.

Large-project detailed analysis can still be slow or **Partial**. The original
private firmware and a real Windows/WSL installation remain unverified. Optional
project-strategy AI and ELF support are design documents, not runtime features
in this release. General Include/Exclude defaults are unchanged in this package.
