# C Relation Explorer 0.1.41

Fix three index and call-graph defects found during the full review.

- **Keep the latest source:** an older disk read can no longer overwrite a newer
  edit in the analysis Worker. Pending reads are also discarded after deletion
  or Rebuild Index. Worker failure during a read no longer leaves the file job
  waiting for a response that cannot arrive.
- **Enforce the file limit:** watched additions and pending file reads now share
  the initial 10,000-file cap. Existing files can still update; deleted or failed
  entries free space. Narrow Include/Exclude and rebuild to choose the scope.
- **Correct Callers:** calls inside unevaluated `sizeof` expressions no longer
  appear as executed calls. References still shows the source use.

An unexpected persistent analysis-version mismatch now reports a partial index
with a Rebuild Index instruction instead of silently showing Index ready.
This release does not raise the Worker heap limit or change the memory guard.

Install the VSIX for Windows, macOS or WSL, reload VS Code and confirm
**v0.1.41** in the Relation toolbar. In WSL, install into the WSL extension host.
