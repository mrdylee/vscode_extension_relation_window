# C Relation Explorer 0.1.33

- Fix pathological repeated-header traversal that could keep **Resolving calls
  and callbacks…** busy and block later source updates in the analysis Worker.
- Count header visits as well as existing macro events/depth. When the new visit
  limit is reached, affected files retain source-call candidates and show
  **Macro include traversal limit reached** in Analysis notices. Macro/callback
  derivation for those incomplete files is skipped instead of using a prefix.
- Keep ordinary symbol navigation, header-edit recovery and later Relation
  updates available. Existing macro-event/depth handling remains unchanged.
- Retain the v0.1.32 member, function-argument, Settings and layout features.

## Update

Run **C Relations: Check for Updates → Update**, then **Developer: Reload Window**.
Alternatively install a VSIX below through **Extensions: Install from VSIX…**.
Verify **Context v0.1.33**. In WSL, update from the WSL-connected VS Code window.
Windows/macOS/WSL-labelled files are identical universal packages.

The reproduced include-graph defect is fixed; the user's private WSL workspace
was not directly inspected. Very large macro/callback workloads can still take
time, and Analysis notices continue to identify partial results. This release
does not introduce a whole-project time limit.
