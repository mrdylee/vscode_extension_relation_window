# Dynsight 0.1.71 — Local analysis Stop and per-function progress

## Local callback analysis

- Remove the project-wide 10-second cutoff. No total time-budget setting is added.
  Memory, work, slot and convergence protections remain in place.
- Show the current function's elapsed analysis time and reset it at the next
  visit. Visits lasting at least five seconds show **Taking longer** without an
  automatic stop. This measures static analysis, not a callback's runtime.
- Use **Stop local** to interrupt propagation, macro expansion and final
  registration-candidate collection. Preserve discovered results and partial
  status. Ordinary source edits do not resume a manually paused pass.
- Use **Retry local** to retry relationships using parsed sources. The command
  palette also offers **Dynsight: Stop Local Analysis / Resume Local Analysis**.
  These controls do not enable Copilot.
- Report manual cancellation accurately and keep collected registration facts
  without caching partial output as complete.
- Preserve fatal Worker errors even when they occur during request dispatch.
  Keep unchanged Relation graphs during status/diagnostic refreshes; source and
  graph-setting changes still update relationships.

## Cache migration

Analysis compatibility remains version 3. Old fixed-deadline caches reuse parsed
sources and automatically recompute relationships once. A valid 0.1.69 index
needs no manual Rebuild. Cancelled/transient generations are not validated as
completed derived caches.

0.1.70 was an unpublished CI candidate; installed versions update directly to
0.1.71. Separate conditional-preprocessor parser findings in analysis.md remain
outside this release. Original firmware performance was not measured here.
