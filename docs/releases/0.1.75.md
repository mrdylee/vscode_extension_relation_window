# Dynsight 0.1.75 — Smart Analysis settings and macro/callback precision

## WSL download

Install `dynsight-0.1.75-wsl.vsix` in the WSL extension host. In a VS Code window
connected to WSL, run **Extensions: Install from VSIX…**, select the file, and
reload when requested. Verify Dynsight 0.1.75 under **Installed in WSL**.
Windows, macOS and updater aliases contain the same universal JS/WASM package.
Checksums are supplied in `SHA256SUMS.txt`.

## Changes

- Settings use four path lists: **Include**, **Exclude**, **Smart Analysis Include**
  and **Smart Analysis Exclude**. Smart Analysis has two switches: **Macro**,
  covering macro expansion and local callback propagation, and **Copilot**.
  An empty Smart Analysis Include keeps basic navigation active without starting
  scoped smart analysis. Existing legacy values and explicit restrictions are
  preserved until the new scope is saved.
- Enabled Copilot analysis can investigate eligible callbacks even when Macro
  is off. The footer explains when callback sites are outside the AI scope;
  it no longer treats those sites as if none existed. Automatic requests remain
  serial, reuse valid cache and respect saved scope and user confirmations.
- Conditional macro choices retain their correlation. Repeated numeric choices
  avoid redundant reparses, and valid C statements split by preprocessor branches
  are recovered without suppressing genuinely malformed syntax.
- Callback analysis separates borrowed caller objects from shared helper state
  and avoids duplicate reachable-object traversal. Macro work no longer consumes
  the full callback work allowance before callback analysis starts. Existing
  mutation, region, context, loop and memory bounds remain in force.
- Basic macro uses bind to visible definitions using include/define/undef metadata,
  without expanding bodies. Alternative definitions with the same binding set
  share a node; the popup lists definition locations for navigation. Basic results
  and their bindings survive Stop and memory-limited detailed analysis.
- Analysis cache compatibility is **8**. Incompatible saved analysis is rebuilt;
  user-confirmed callback targets remain stored separately. The fixed Stop local
  position, single-row footer and full-function-name hover/Copy remain available.

## Verification and limits

Synthetic regression tests cover the reported callback eligibility and macro
binding cases. The original private firmware and a Windows/WSL installation are
not available in this checkout. Copilot tests use a mock provider.

Detailed analysis of large projects can still be slow or **Partial**. Work batches
are accounting boundaries, not saved checkpoints or a new background scheduler.
Basic binding adds metadata work, and conditional or missing-header bindings can
overapproximate candidates. Candidate lists are not compiler-confirmed results.
This release does not claim complete full-project FreeRTOS or firmware analysis.

Cross-platform CI, packaged-runtime checks and downloaded-asset verification are
recorded in `docs/reviews/2026-10-23-release-0.1.75.md` after publication.
