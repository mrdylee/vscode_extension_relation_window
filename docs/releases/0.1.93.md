# Dynsight 0.1.93

Fixes a missing callback candidate after conditional include-guard changes. A header ending in a conditional `#undef` can be re-entered on one path and skipped on another; macro expansion now retains both possibilities. Conditional guard definitions before inclusion also preserve the skipped path.

The correction shares the existing uncertain-guard handling between reference binding and full macro expansion. Known unconditional guard states and the guarded-prefix optimization remain intact. Source scopes, analysis bounds and AI settings are unchanged.

Regression coverage includes cold/warm derivation, unconditional guard/reset controls, header edits and Worker disk-cache restoration. The actual RBMS workspace is checked with the same 147-file scope and root `Build_RBMS.bat` selection/rebuild, without executing the build or sending AI requests.

Analysis cache compatibility is now **19**. Use **Rebuild index** after upgrading an existing cache. Unsupported Diab options and generators still leave build membership unverified; full source fallback remains available.
