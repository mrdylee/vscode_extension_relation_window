# C Relation Explorer 0.1.13

고정 버튼이 현재 상태를 명확히 표시합니다.

- **자동 추적 중**: 메인 코드 또는 Context에서 선택한 심볼을 따라 Relation이 갱신됩니다. 클릭하면 고정합니다.
- **고정됨 · 추적 중지**: Relation을 유지합니다. 클릭하면 고정을 해제하고 자동 추적을 재개합니다.
- 마우스를 올리면 클릭 시 수행할 동작이 표시됩니다.

기존의 `고정 해제` 문구는 현재 고정 상태에서 누르면 해제한다는 뜻이었습니다. 이번 버전은 표시를 명확히 하며, 고정/추적 및 Context 이동 로직 자체는 변경하지 않습니다. 실제 WSL에서 발생한 멈춤 증상이 해결됐다고 보장하는 변경은 아닙니다.

## 검증

로컬 브라우저에서 버튼의 양방향 상태 표시를 확인하며, Extension Host에서 고정 중 Context 이동과 고정 해제 후 선택 추적을 검증합니다. Windows/macOS/Ubuntu의 타입·단위·Extension Host 검증을 통과한 후 게시합니다.
