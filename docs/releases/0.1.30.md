# C Relation Explorer 0.1.30

Open **Settings** in the Relation toolbar to configure sorting, Context layout,
call graph direction and Include/Exclude together.

- **Call Graph Direction**: choose **Callers left / Callees right** (default), or
  **Callees left / Callers right**. Applies to **Callers & Callees** mode. Existing
  expansion and selection are preserved; no new analysis pass is started.
- The complete graph starts at the left edge, with left branches visible. The
  selected function is no longer automatically centered in the viewport.
- **Callee Sort**: name or first-call source order. **Context Layout**: Combined or
  Separate. These preferences now live in Settings. Right-click offers Settings
  and Reset graph position.

Use **Extensions: Install from VSIX…**, then **Developer: Reload Window**. Once this
version is published, **C Relations: Check for Updates** can also install it. Verify
**Context v0.1.30**. Install from a WSL-connected window when using WSL.
