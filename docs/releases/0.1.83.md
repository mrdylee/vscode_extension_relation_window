# Dynsight 0.1.83 — Saved symbols and Backspace navigation

Five numbered slots beside Following selection now save functions or variables
from Relation. Right-click the symbol you want to remember and choose Save to
slot 1–5. Hover over a populated slot to see its name, then click to restore its
tree options and expanded branches and open its current source location.

Each slot has an independent padlock. Locked slots still open, while replacement
and clearing require unlocking. Slots persist in the current workspace. Recall
pins the restored tree; use Following selection to resume editor tracking.

Press Backspace in Relation to undo the latest expansion, one step at a time.
Input fields keep their normal text deletion behavior. The shortcut preserves
the root and canvas position, including when undo removes the focused node.
Review fixed a race that could retain obsolete Back history while source updates
arrived during expansion.

Saved symbols are resolved against current code and their source context.
Unavailable symbols are reported and changed branches may be partly restored.
Existing analysis scope, cache compatibility and analysis limits remain unchanged.

Install the matching Windows/macOS/WSL VSIX and reload VS Code.
