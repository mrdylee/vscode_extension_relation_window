# Dynsight 0.1.85 — Complete saved trees and action undo

Slots now save the entire current Relation view: its original root, caller and
callee branches, expansion/collapse states and graph options. If you right-click
B in a tree rooted at A and save it, recalling the slot restores the whole A
tree and selects B, opens B's current definition and shows it in Context.
The exact occurrence remains selected even when the same function appears on
both sides of the tree.

Slot recall keeps Following Selection or the existing pin state. It also keeps
the full graph when the selected symbol opens in another source/build file.
Failed source opening preserves the previous view and undo history, and rapid
recalls no longer allow an earlier timeout to resume tracking too early.

Backspace in Relation undoes the latest expansion or collapse while keeping the
current selection and Context preview. It does not navigate back to a previously
selected function. Editable fields retain normal deletion.

Existing slots and locks remain readable. Old descendant-only slots do not
contain their former parent/sibling tree; save those slots again to capture the
complete view. Relationships are reconstructed from current code, with partial
restoration reported when saved branches are unavailable.

Analysis cache compatibility remains 16. Install the matching Windows/macOS/WSL
VSIX and reload VS Code.
