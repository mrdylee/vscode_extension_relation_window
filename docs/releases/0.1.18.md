# C Relation Explorer 0.1.18

- Settings now offers **Include** (`cRelation.include`) and **Exclude** (`cRelation.exclude`). Include is empty by default, meaning all C/H files. Exclude always wins. Both use workspace-relative glob patterns and forward slashes; changes automatically rebuild the index.
- Example: include `["App/**", "Drivers/**"]`, exclude `["**/generated/**", "**/test/**"]`. No include matches means zero indexed files; use an empty include list to restore full scope.
- Fix double-click opening the wrong symbol when first-click expansion moves the graph. Includes the menu-stability and click-expansion changes prepared in 0.1.17.

Install the universal VSIX using **Extensions: Install from VSIX…**, then **Developer: Reload Window**. Verify **Context v0.1.18**. For WSL, install into the WSL-connected VS Code window. See README for detailed scope settings.
