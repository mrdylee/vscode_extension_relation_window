# Dynsight 0.1.84 — Compact slot padlocks

The padlock now overlays the upper-right corner of each slot number. Empty,
unlocked and locked slots keep the same compact width instead of growing when a
padlock appears.

Click the padlock to lock or unlock a saved slot, and click the number to recall
its symbol and tree. Saved-name tooltips, slot persistence and Backspace
navigation retain their existing behavior.

Install the matching Windows/macOS/WSL VSIX and reload VS Code.
