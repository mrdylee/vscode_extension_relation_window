# Dynsight 0.1.98

Meet Salgu, a small cat in the Relation panel. Once the panel is visible and
VS Code reports that the focused window is idle, Dynsight waits **three minutes**
before playing one of ten short scenes. Salgu can peer around an edge, walk
across the panel, catch a butterfly, eat, or pop up at all four edges in random
order.

Panel input hides Salgu and restarts the wait. The animation respects reduced
motion and uses a single 44 KB sprite sheet.

Run **Dynsight: Check for Updates** or install the VSIX for your platform in
VS Code. The Windows, macOS, and WSL downloads contain the same extension.
