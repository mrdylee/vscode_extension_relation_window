# Dynsight 0.1.63 — WSL compact status bar

The bottom status bar now shows **Index status → Copilot → Analysis notices**
from left to right in a single row. Long status text uses ellipses instead of
adding rows, leaving more room for Context and Relation.

Expand **Analysis notices** to read its details above the status bar. Diagnostics
and **Analyze next 5** remain available.

Install `dynsight-0.1.63-wsl.vsix` in the WSL extension host and reload VS Code.
This release distributes the WSL package only; the suffix-free and legacy
filenames contain the same bytes for existing automatic updaters. No Windows
or macOS download copies are provided.

Validation uses Ubuntu/Linux and browser UI checks. A live WSL remote session
has not been tested in this environment.
