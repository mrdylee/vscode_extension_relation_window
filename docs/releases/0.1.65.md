# Dynsight 0.1.65 — Windows / macOS / WSL

## Automatic Copilot analysis with Stop

- Click **Analyze all remaining** once, or run **Dynsight: Analyze Callbacks with
  Copilot**, to continue through pending callbacks in batches of five. Progress
  stays cumulative and valid cached results are reused.
- Click **Stop analysis** or run **Dynsight: Stop Copilot Analysis** to cancel the
  current request and preserve completed results. Analyze resumes missing sites.
  Saving alone does not restart a stopped job.
- Active jobs pause during unsaved edits and continue after saving/local indexing.
  Request errors stop automatic continuation. Each new request uses your Copilot
  allowance; startup/navigation still only restore cache. Background saved-file
  analysis remains limited to five new requests when no explicit full job is active.

## AI candidate function navigation

Click an AI candidate function in Callees to preview its actual definition in
Context and expand its callees. Double-click or press Enter to open its definition
in the editor. The original callback invocation and registration evidence remain
separately accessible from the details popup. AI candidate warnings are preserved;
navigation does not prove runtime invocation.

## Downloads

Install the file for your environment and reload VS Code:

- Windows: `dynsight-0.1.65-windows.vsix`
- macOS: `dynsight-0.1.65-macos.vsix`
- WSL: `dynsight-0.1.65-wsl.vsix`, installed in the WSL extension host

These downloads and the common/legacy automatic-update filenames contain the same
universal JavaScript/WASM package. SHA256SUMS.txt lists their checksums. Release CI
tests Windows, macOS and Ubuntu; live WSL remote installation is not verified here.
