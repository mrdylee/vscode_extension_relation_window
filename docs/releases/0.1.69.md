# Dynsight 0.1.69 — Callback offsets and GNU declarations

This release fixes the remaining callback-analysis findings in analysis.md and
the subsequent review.

## Callback analysis

- Separate pointer address selection from pointed-to numeric data. Dynamic and
  unexpanded-macro offsets, pointer guards and member buffers no longer turn
  unrelated byte packing into callback mutation/region limits. Actual callback
  selectors and aliases remain tracked.
- Compose element offsets through direct assignments, returned pointers, local
  aliases, wrapper arguments and invalidation regions. Preserve real nested
  arrays and zero indexing of addressed scalar objects. Wildcard aliases retain
  possible targets conservatively.
- Recover valid GNU attribute declarations while preserving source positions,
  conditional declarations and macros. Malformed attributes and unrelated syntax
  errors remain visible.

The existing 256-slot and 10-second analysis limits remain in place. Synthetic
regressions are covered; the original firmware project was unavailable for
verification.

## Rebuild required

Analysis compatibility advances from 2 to 3 because parsed and inferred results
have changed. Run **Dynsight: Rebuild Index** once after upgrading. Compatible
future updates continue to reuse indexes. Rebuild alone does not start paid AI
requests.
