# Dynsight 0.1.72 — Scoped analysis and user-confirmed callbacks

## Settings and local analysis

Settings now follow View → Include → Exclude → Detailed Analysis Folders →
Analysis Options → Relation Display → Copilot, followed by maintenance settings.
Use **Detailed Analysis Folders** to select macro expansion and full callback
propagation together. New workspaces start with `[]`: basic symbols, direct
calls, explicit registrations and supported simple pointer candidates remain.

Include/Exclude still control indexing. Indexed header definitions are available
to selected sources; external function bodies are not traced automatically.
Explicit legacy settings and cached existing roots retain their policy until a
unified detailed scope is saved. An explicitly saved empty list disables detailed
analysis. No clangd, Python search process or compiler setup is required.

Per-function and project work bounds complement the existing memory, slot and
convergence limits. Partial results retain their reason and **Retry local**.
Narrowing detailed folders releases full propagation data. Selecting an entire
large project can still reach work or memory limits; partial results are not a
claim of complete callback coverage.

## Callback investigation and user choices

- **Find target with AI** investigates one selected unresolved call. Startup,
  enable, save, rebuild, navigation and model selection send no new AI requests.
  Copilot Include/Exclude must allow the call within the detailed scope.
- An **AI candidate** popup offers **Set manually** and **Recheck with AI**.
  Choose an indexed function; same names show their file paths, and obvious
  signature mismatches are disabled. Applied choices show **User confirmed**.
- A **User confirmed** popup offers the same actions. AI agreement or a different
  suggestion preserves the user choice. Only **Use this target** applies the
  selected suggestion, which remains **User confirmed**.
- User choices are stored independently of AI cache and survive restart,
  Rebuild, model changes and Copilot OFF. Changed source/dependencies require
  review. **Remove manual override** removes only that choice.
- AI rechecks remain available after local analysis resolves the call. Changing
  a manual choice preserves registration dependencies across restart.

AI candidates, explicit registrations and user confirmations are evidence levels,
not runtime proof. Actual Copilot model accuracy was not measured by mock tests.

## Progress and compatibility

**Stop local** has a fixed action area and a separate row in narrow panels.
Hover or focus the shortened function name for selectable full text and **Copy**.
An open popup keeps the sampled name even as analysis moves to another function.

This package also includes embedded C attribute/conditional-initializer parsing
fixes. Analysis compatibility is **5**: if a saved index reports incompatibility,
run **Rebuild index**. User-confirmed choices are stored separately.

Generic Windows/macOS/Linux CI is separate from validation on a real Windows
SafeRTOS/Wind River firmware workspace, which remains unverified.
