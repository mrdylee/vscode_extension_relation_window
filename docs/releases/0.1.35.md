# C Relation Explorer 0.1.35

- **Settings → Context Layout → Combined · Full width** displays Context and
  Relation together across the bottom, beneath both sidebars. Switch to
  **Combined** or **Separate** to restore the editor-width panel. VS Code shares
  this panel alignment with Terminal and other bottom-panel views.
- Pinning now places a compact pushpin on the Relation root. Hover over
  **Pinned · Follow paused** to see which symbol is pinned. Unpin removes the
  marker and resumes following selection. Existing branch expansion, source
  navigation and graph panning remain available.
- Updated the bundled Help and README with all three layout choices and pin
  indicators. Existing settings and analysis behavior are preserved.

Windows, macOS and WSL downloads contain the same universal VSIX. In WSL, install
in the WSL extension host. After replacing an older installation, use
**Developer: Reload Window** and confirm **C Relations v0.1.35** in the toolbar.
