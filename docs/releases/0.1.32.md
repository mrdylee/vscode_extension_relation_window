# C Relation Explorer 0.1.32

This release includes the improvements developed since v0.1.29.

## Member navigation without a build

- Resolve fields through explicit casts such as `((Motor *)p)->state` and
  declared return types such as `get_motor()->state`.
- Follow fields promoted by anonymous struct/union members, keeping unrelated
  same-named fields separate.
- Select fields in designated initializers, nested field/array paths and compound
  literals. Terminal field designators appear as writes at their original source
  locations; intermediate fields remain selectable.
- Keep original Context/editor navigation, variable R/W filters and header-change
  invalidation. Unsupported expressions produce Analysis notices. Complex
  positional initialization and unavailable types can remain unresolved.

## Function arguments and Settings

- Enable **Settings → Include Function Arguments** to show passed functions in
  Callers, Callees and Callers & Callees. This is off by default. Cyan dotted
  connectors identify argument passing; the popup shows the receiver and argument
  position. Passing a function does not prove it executes.
- Configure **Call Graph Direction** to place callers or callees on either side.
  The complete graph starts at the left edge and preserves expanded branches.
- Use the toolbar **Settings** button for sorting, Context layout, graph direction
  and Include/Exclude. Bundled offline Help covers the new features and limits.

## Install or update

Choose the Windows, macOS or WSL VSIX below. These are byte-identical copies of
the same universal extension, labelled for convenient downloading.

Use **C Relations: Check for Updates → Update**, then **Developer: Reload Window**,
or run **Extensions: Install from VSIX…**. Check that the Context title shows
**v0.1.32**. In WSL, install from the WSL-connected VS Code window.

C/H source folders still work without a compiler, SDK or compilation database.
Inferred relationships remain possible source targets rather than runtime proof.
