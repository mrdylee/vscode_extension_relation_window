# Dynsight 0.1.102

Salgu now performs 40 animated scenes in the Relation panel, including
20 new scenes such as tiptoeing, a slow blink, and a paw wave. Floor-level
scenes end with Salgu leaving through the side of the panel.

Click Salgu, or press Enter when Salgu has keyboard focus, to get a blink and a
heart. The scene resumes after the greeting. To hide Salgu immediately, uncheck
**Salgu: Enabled** in VS Code Settings or set `dynsight.salgu.enabled` to `false`.
Salgu also follows changes to VS Code’s Reduce Motion setting.

Run **Dynsight: Check for Updates** or install the VSIX for your platform in
VS Code.
