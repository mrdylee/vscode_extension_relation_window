# Dynsight 0.1.99

Salgu plays one short scene after **one minute without input in the Relation
view**. Keep Relation visible and VS Code focused. Clicking, scrolling, or
typing in Relation starts a new one-minute wait. You can keep working in the
main editor while the timer runs.

Run **Dynsight: Check for Updates** or install the VSIX for your platform in
VS Code. The Windows, macOS, and WSL downloads contain the same extension.
