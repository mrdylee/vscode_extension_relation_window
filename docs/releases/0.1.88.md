# Dynsight 0.1.88 — One AI setting, two guided choices

**Smart Analysis: AI 하나만** 설정합니다. 별도 Provider·Copilot Model 설정 칸은 숨겼습니다.

1. AI를 체크합니다.
2. **1/2: 사용할 확장** — 설치된 Copilot / Claude Code / Codex 중 하나를 고릅니다.
3. **2/2: 사용할 모델** — 바로 이어지는 목록에서 모델 이름 또는 **Default model**을 고릅니다.

두 선택을 마친 뒤에만 함께 저장합니다. 중간에 취소하면 새로 켠 체크가 꺼지고 이전 선택은 보존됩니다. 변경하려면 같은 설정의 **Choose or change AI extension and model…** 링크나 **Dynsight: Configure Smart Analysis AI**를 사용하세요. 문자열이나 모델 ID를 입력할 필요가 없습니다.

모델 목록은 선택한 확장에서만 조회하며, 설정 중에는 소스나 추론 프롬프트를 보내지 않습니다. Claude Code·Codex의 추가 목록을 불러오지 못한 경우에는 명시적인 기본 모델 선택지를 제공합니다. 선택한 확장과 모델만 분석에 사용하고, 전환 시 이전 요청을 취소합니다. 실패해도 다른 제공자로 자동 전환하지 않습니다.

The single **Smart Analysis: AI** checkbox opens an extension picker, followed immediately by a model picker. Provider and model are saved as one workspace choice after both steps complete. Cancel keeps the previous choice and turns a newly enabled checkbox off. The same setting link opens the complete flow again.

Model catalogs use display names from the selected extension. Claude Code/Codex also offer an explicit default-model item, including when additional model metadata is unavailable. Setup sends no source or inference prompt. Existing single-provider execution, cancellation, evidence validation, manual confirmations and model-specific cache behavior remain supported. Analysis cache compatibility stays at 16.
