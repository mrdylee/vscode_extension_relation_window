# C Relation Explorer 0.1.12

**Context 코드 클릭 → 메인 코드 위치 이동 → Relation 갱신**을 추가했습니다.

- Context에서 함수·변수를 클릭하면 메인 편집기의 해당 줄·토큰 시작으로 이동합니다.
- 고정 해제 상태에서는 클릭한 심볼로 Relation이 바뀝니다. 고정 중에는 기존 Relation을 유지하고 메인 코드만 이동합니다.
- 줄 번호/빈 공간은 줄 시작으로 이동합니다. 텍스트 드래그 선택은 복사를 위해 이동하지 않습니다.
- 한글·이모지·Windows 줄바꿈을 고려하며 오래되거나 범위를 벗어난 미리보기 위치는 무시합니다.
- 기존 Relation 노드 클릭과 1초 지연 상세 팝업은 그대로 사용할 수 있습니다.

기존 설치의 **C Relations: Check for Updates** 또는 **Extensions: Install from VSIX…**로 설치한 뒤 창을 다시 로드하세요. WSL은 WSL에 연결된 창에서 설치하고 Context 왼쪽의 버전이 **0.1.12**인지 확인하세요. 세 환경용 파일은 동일한 범용 JavaScript/WASM 패키지입니다. 접미사 없는 VSIX는 공통 자동 업데이트용입니다.

## 검증

Windows/macOS/Ubuntu의 타입·단위·Extension Host 검증을 통과한 후 게시합니다. 로컬 브라우저에서 클릭한 위치, 드래그 선택, UTF-16/CRLF 처리를 검증했습니다. 실제 Extension Host에서 메인 코드 이동, 함수·변수 관계 전환, 다른 파일 이동, 고정 유지, 잘못된 요청 무시를 검증했습니다. 사용자 WSL 원격 환경의 직접 검증은 아직 수행하지 못했습니다.

Polyspace 헤더의 크기·문법 분석 알림과 분석 범위는 이번 버전에서 변경하지 않습니다.
