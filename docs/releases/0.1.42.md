# C Relation Explorer 0.1.42

Avoid unnecessary analysis while navigating unchanged source files.

- **Reuse unchanged results:** closing a document, including VS Code document-cache
  eviction during navigation, no longer reparses identical source or restarts
  project call/callback analysis. Duplicate watcher notifications also reuse it.
- **Keep changes accurate:** edits, discarded unsaved edits and external file
  changes still update the index. Returning to the original text while a previous
  analysis response is pending correctly restores the Worker's source state.

This fixes a reproduced unnecessary-analysis path. It does not establish the exact
cause of the reported private WSL project's memory peak or guarantee complete
analysis within the memory budget. The Worker memory guard remains unchanged.

Install the VSIX for Windows, macOS or WSL, reload VS Code and confirm **v0.1.42**
in the Relation toolbar. In WSL, install into the WSL extension host. After the
initial index finishes, unchanged-file navigation should reuse its results.
