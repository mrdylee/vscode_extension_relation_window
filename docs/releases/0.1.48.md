# Dynsight 0.1.48

Pin the symbol you selected in Relation.

- Click a Relation node, then **Following selection** to pin that symbol as the
  new root. With no node selected, the current root is pinned.
- Right-click a resolved node and choose **Pin this symbol** to set or replace
  the pin, including while already pinned.
- The pushpin marker and **↩ Pin** follow the new pinned symbol.
- Click **Pinned · Follow paused** to remove the pin and resume editor tracking.

Help and README include the updated workflow. This release changes navigation
only; it does not change indexing or resolve the ongoing WSL file-count/host
restart investigation.
