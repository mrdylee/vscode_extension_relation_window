# C Relation Explorer 0.1.38

Add **Diagnostics** in the Relation footer for photographing memory problems.

- See version/environment, Worker heap used/limit and the 60% guard, sampled peak,
  external memory, source/macro/callback checkpoints and first budget hit.
- A new memory incident or Worker failure opens the summary once. Close it to
  continue navigation. A stopped Worker retains its timestamped last sample.
- Extension-host heap is shown separately as shared memory. Diagnostic updates
  are bounded and do not rebuild the relation graph.
- Offline Help explains how to capture the full summary **before Rebuild index
  or Reload Window**. Increase panel height if needed.

This update adds measurements; it does not raise memory limits or change inference.
Samples include cache and garbage-collection effects and are not total system RAM.
