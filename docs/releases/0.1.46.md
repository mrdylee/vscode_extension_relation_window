# Dynsight 0.1.46

**Diagnostics → Report issue** now gathers more evidence for freezes and restarts.

- Current diagnostic snapshot plus saved recent sessions, memory samples and
  navigation action types. Three sessions retained with bounded storage and queues.
- Available Extension Host / Remote Server lifecycle and OOM excerpts. Missing
  files and unsupported log layouts are explicitly reported.
- **Save report** saves your reviewed Markdown draft as one file to share.
  Copy actions remain available; nothing is uploaded automatically.

Host excerpts may contain private metadata. Known home/workspace roots and URLs
are redacted, but review the file before sharing. WSL cannot collect Windows-side
Window logs. Pending writes can be lost on abrupt termination; history begins
with this version. This improves evidence collection and does not claim to fix
the unexplained freeze or host restart.

Install the Windows, macOS or WSL VSIX, reload once, confirm **v0.1.46**. Reproduce,
then use **Diagnostics → Report issue → Save report** and share that `.md` file.
