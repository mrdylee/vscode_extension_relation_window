# C Relation Explorer 0.1.10

C 소스 폴더만 열어 함수의 호출·참조 관계와 변수의 읽기·쓰기 위치를 탐색하는 VS Code 확장입니다. 빌드나 별도 C 컴파일러 설정이 필요하지 않습니다.

## 다운로드

| 환경 | 설치 파일 |
| --- | --- |
| Windows | [Windows VSIX](https://github.com/mrdylee/vscode_extension_relation_window/releases/download/v0.1.10/c-relation-explorer-0.1.10-windows.vsix) |
| macOS (Apple Silicon / Intel) | [macOS VSIX](https://github.com/mrdylee/vscode_extension_relation_window/releases/download/v0.1.10/c-relation-explorer-0.1.10-macos.vsix) |
| WSL | [WSL VSIX](https://github.com/mrdylee/vscode_extension_relation_window/releases/download/v0.1.10/c-relation-explorer-0.1.10-wsl.vsix) |

세 파일은 같은 JavaScript/WASM 기반 범용 패키지입니다. 환경을 쉽게 선택하도록 파일 이름만 구분했습니다. 별도의 네이티브 실행 파일은 포함하지 않습니다. 접미사 없는 `c-relation-explorer-0.1.10.vsix`는 같은 내용의 공통·자동 업데이트용 파일입니다. `SHA256SUMS.txt`로 다운로드 무결성을 확인할 수 있습니다.

## 설치

- VS Code 데스크톱 1.95 이상에서 명령 팔레트의 **Extensions: Install from VSIX…**를 실행하고 받은 파일을 선택합니다.
- WSL: Windows에 VS Code와 Microsoft WSL 확장을 설치하고 **WSL: Reopen Folder in WSL**로 소스 폴더를 연 다음 VSIX를 설치합니다. 확장 목록의 **WSL: 배포판 이름** 쪽에 설치됐는지 확인합니다. 필요하면 **Install in WSL**을 선택합니다.
- C 파일에서 함수·변수 이름을 클릭하고 **C Relations: Open Relation and Context**를 실행합니다.

## 포함 기능

- 실제 호출 위치를 포함한 관계 트리와 연결된 코드 미리보기
- 1~8단계 탐색, 함수·변수 아이콘, 구문 색상, 1초 정지 후 상세 팝업
- 변수 읽기 / 쓰기 / 읽기·쓰기 / 주소 사용 필터
- 확정 가능한 `#if 0` 비활성 코드 제외
- GitHub 정식 릴리스 자동 확인 및 사용자 동의 후 업데이트 설치

## 검증 범위

이 릴리스는 Windows·macOS·Ubuntu의 타입 검사, 33개 단위 테스트 및 VS Code Extension Host 통합 테스트를 통과해야 게시됩니다. macOS에서는 FreeRTOS 655개 파일 분석도 확인했습니다. Ubuntu 검증은 WSL의 실제 원격 연결 테스트를 대체하지 않으며, WSL 연결 및 원격 자동 업데이트 설치는 아직 실환경 미검증입니다. 웹 전용 VS Code는 지원하지 않습니다.
