# Callees Implementation Plan

> **For agentic workers:** REQUIRED EXECUTION SKILL: Use superpowers:executing-plans for continuous inline implementation. No subagents.

**Goal:** Add outgoing call navigation without changing stable incoming navigation.

**Architecture:** Maintain per-function outgoing reference buckets alongside the
existing incoming name buckets. Reuse scoped resolution and bounded graph
traversal; pass call classification to the existing webview and preview handler.

**Tech Stack:** TypeScript, Tree-sitter C WASM, VS Code Webview, node:test, Playwright.
