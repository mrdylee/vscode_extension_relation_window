# Context 클릭 탐색

사용자가 Context의 코드를 클릭하면 해당 파일·줄·토큰 위치를 메인 코드 창에서 표시하고, 고정 해제 상태에서 클릭한 심볼의 Relation으로 전환한다. 고정 상태에서는 메인 코드만 이동하며 기존 관계를 유지한다.

단일 클릭이 요청과 맞는다. 더블클릭은 기존 관계 노드 동작과 비슷하지만 이번 Context 탐색에는 불필요한 조작이므로 사용하지 않는다. 코드 드래그 선택은 복사 용도로 보존한다.

Webview의 토큰 시작 열(UTF-16)과 원본 줄 번호를 전달한다. 줄 번호·빈 공간은 해당 줄 시작으로 이동한다. 호스트는 현재 미리보기의 URI·줄 범위·내용·열을 확인하고 실제 문서 내용과도 일치할 때만 이동한다. 임의 URI나 오래된 미리보기 메시지는 무시한다.

기존 Relation 노드의 소스 열기는 루트를 유지한다. Context의 명시적 이동은 별도 메시지로 구분하고 기존 자동 추적 로직을 호출한다. 큰 리팩터링이나 새 창은 필요하지 않다.

검증: 브라우저 클릭 위치, 드래그 선택, 실제 Extension Host의 파일/커서 이동, 함수·변수 관계 전환, 고정 유지, 잘못된 메시지 무시. WSL 직접 실행은 확인 가능한 환경이 없으므로 별도 한계로 보고한다.
