# Compact Relation + Context 색상

사용자 요청: Relation의 카드당 여러 줄을 제거하고 아이콘과 심볼 이름만 표시한다. 마우스를 올리면 세부 정보를 보여주고 클릭은 왼쪽 Context에 반영한다. tint는 구문 색상 강조로 해석한다.

한 줄 높이 26px 이하, 노드 사이 간격 6px로 만든다. 상세 정보는 그래프 레이아웃에 영향을 주지 않는 팝업으로 옮긴다. 일반 브라우저 title 툴팁은 위치를 클릭할 수 없어 사용하지 않고, 항상 표시하는 옆 상세 패널은 그래프 너비를 차지하므로 사용하지 않는다.

노드 클릭은 심볼 정의를 Context에서 미리 본다. 팝업에는 전체 심볼 이름, 종류, 원본 경로/줄, 참조 위치별 버튼, 조건/후보/재귀 상태, 펼침/접기/추가 단계 버튼을 표시한다. 팝업으로 마우스를 옮겨도 닫히지 않으며 스크롤·화면 경계 안에서 표시한다. 포커스 또는 Space로 열고 Escape로 닫는다. 기존 방향키·Enter·더블클릭 동작은 유지한다. 후보/조건은 아이콘의 표시와 접근성 설명에도 남긴다.

Context는 C 토큰을 키워드, 타입, 함수명, 매크로/상수, 변수, 숫자, 문자열, 주석, 전처리 지시자로 구분해 표시한다. 전체 파일에서 토큰화한 뒤 Context 범위를 잘라 긴 블록 주석의 중간에서도 색상을 보존한다. 문자열을 HTML로 실행하지 않는다. 문법 기반 색상이며 사용자 정의 타입/매크로의 완전한 의미 분석은 범위 밖이다. 밝은/어두운 테마를 지원한다.

통과 기준: 여러 참조를 가진 노드도 한 줄이며 hover로 높이가 바뀌지 않음, 두 번째 참조 클릭이 정확한 줄을 강조, 키보드 상세 접근/확장 유지, 긴 주석·문자열 내부를 함수로 강조하지 않음, 테마별 색 구분, 실제 VS Code 통합 통과.
